01

อินเทอร์เน็ตคืออะไร?

จากคอมพิวเตอร์ 1 เครื่อง → เครือข่ายของเครือข่ายทั้งโลก

อินเทอร์เน็ต (Internet) มาจาก Inter-connected Network คือ เครือข่ายคอมพิวเตอร์ที่ใหญ่ที่สุดในโลก เกิดจากเครือข่ายย่อยนับล้านเชื่อมกัน จึงเรียกว่า “เครือข่ายของเครือข่าย” ทุกเครื่องคุยกันด้วย “ภาษากลาง” ชุดเดียวกันชื่อ TCP/IP และมีเลขประจำตัวเรียกว่า IP Address

ไม่มีใคร “เป็นเจ้าของ” อินเทอร์เน็ตทั้งหมด — แต่ละเครือข่ายมีเจ้าของของตัวเอง (ISP บริษัท มหาวิทยาลัย) แล้วตกลงเชื่อมต่อกัน

🛣️
อินเทอร์เน็ต =
ระบบถนนเชื่อมทุกที่เข้าด้วยกัน
🚚
บริการ (WWW, Email) =
รถที่วิ่งบนถนนแต่ละคันทำหน้าที่ต่างกัน
🏠
IP Address =
บ้านเลขที่ห้ามซ้ำกันบนเครือข่าย
🚪
Port =
ประตูของบ้านแต่ละบริการใช้ประตูต่างกัน
🚦
TCP/IP =
กฎจราจรทุกคันต้องใช้กฎเดียวกัน

ข้อมูลไม่ได้วิ่งเป็นก้อนเดียว แต่ถูกหั่นเป็น แพ็กเก็ต (Packet) เล็ก ๆ แต่ละแพ็กเก็ตอาจไปคนละเส้นทาง แล้ว TCP นำมาเรียงต่อกันใหม่ที่ปลายทาง ถ้าหายระหว่างทางจะขอส่งซ้ำอัตโนมัติ

ข้อมูลข้ามทวีปเกือบทั้งหมด วิ่งผ่านสายเคเบิลใต้ทะเล ไม่ใช่ดาวเทียม เพราะเร็วกว่าและจุข้อมูลได้มากกว่าหลายเท่า ประเทศไทยมีสถานีขึ้นบกของเคเบิลใต้น้ำทั้งฝั่งอ่าวไทยและอันดามัน

02

ประวัติย่อ: จาก ARPANET ถึง AI

ไม่ต้องจำปีเป๊ะ แต่ให้เห็นลำดับวิวัฒนาการ

  1. พ.ศ. 2512 (1969) · ARPANET

    หน่วยงาน ARPA ของกระทรวงกลาโหมสหรัฐฯ เชื่อมคอมพิวเตอร์ 4 แห่ง (UCLA, SRI, UCSB, University of Utah) — จุดเริ่มต้นของอินเทอร์เน็ต

  2. พ.ศ. 2526 (1983) · TCP/IP

    เครือข่ายเปลี่ยนมาใช้ TCP/IP ซึ่งยังเป็นภาษากลางจนทุกวันนี้ · ระบบ DNS ถูกออกแบบในปีเดียวกันและเริ่มใช้งานจริงในปีต่อ ๆ มา

  3. พ.ศ. 2532 (1989) · กำเนิด WWW

    Tim Berners-Lee ที่ CERN เสนอแนวคิดระบบเอกสารเชื่อมโยงด้วยลิงก์ แล้วพัฒนาสำเร็จในปี 1990 ประกอบด้วย HTML · HTTP · URL พร้อมเบราว์เซอร์และเว็บเซิร์ฟเวอร์ตัวแรก

  4. พ.ศ. 2534 (1991) · เว็บไซต์แรกของโลก

    เว็บไซต์แรกทำงานภายใน CERN ตั้งแต่ปลายปี 1990 และเปิดให้คนภายนอกใช้ในเดือนสิงหาคม 1991 ที่ info.cern.ch — CERN นำกลับมาเปิดให้ดูได้จนถึงทุกวันนี้!

  5. พ.ศ. 2535 (1992) · ประเทศไทยเชื่อมอินเทอร์เน็ต

    มหาวิทยาลัยในไทยเชื่อมต่อแบบถาวรกับต่างประเทศ ความเร็วราว 9.6 kbps

  6. พ.ศ. 2536–2541 · เบราว์เซอร์และเสิร์ชเอนจิน

    Mosaic แสดงรูปในหน้าเว็บ → Netscape, Internet Explorer → Google (2541)

  7. พ.ศ. 2547–2550 · Web 2.0 & สมาร์ตโฟน

    Facebook, YouTube, iPhone → ผู้ใช้สร้างเนื้อหาเอง และท่องเว็บบนมือถือ

  8. พ.ศ. 2557 · HTML5 เป็นมาตรฐาน

    เล่นวิดีโอ/เสียงได้โดยไม่ต้องใช้ Flash · เว็บกลายเป็นแอปพลิเคชัน

  9. ปัจจุบัน · Cloud, HTTP/3, AI

    เว็บทำงานบนคลาวด์ ใช้ AI ช่วยสร้างและช่วยค้นหา และต้องรองรับทุกอุปกรณ์

ข้อความแรกที่ส่งผ่าน ARPANET คือคำว่า “LO” — ตั้งใจพิมพ์ “LOGIN” แต่ระบบล่มหลังส่งไปได้ 2 ตัวอักษร 😂

Tim Berners-Lee ไม่จดสิทธิบัตร WWW และเปิดให้ทุกคนใช้ฟรี เว็บจึงเติบโตเร็วมาก — ถ้าเก็บค่าลิขสิทธิ์ เราอาจไม่มีเว็บแบบทุกวันนี้

03

Internet ≠ Web และคำศัพท์ที่ต้องรู้

คำที่คนทั่วไปใช้แทนกัน แต่ความจริงคนละอย่าง

Internet

  • โครงสร้างพื้นฐาน สาย อุปกรณ์ เครือข่าย
  • เกิดก่อน (2512)
  • เหมือน ถนน
  • มีหลายบริการ: Email (SMTP), FTP, SSH, VoIP, Game, WWW
VS

World Wide Web

  • บริการหนึ่ง บนอินเทอร์เน็ต
  • เกิดทีหลัง (2532)
  • เหมือน รถส่งเอกสาร
  • เอกสาร (เว็บเพจ) เชื่อมกันด้วย ไฮเปอร์ลิงก์ ดูด้วย เบราว์เซอร์ ผ่าน HTTP

คำศัพท์ — แตะการ์ดเพื่อพลิก (ลองทายก่อน!)

URL Encoding: URL ส่งได้แค่ตัวอักษรอังกฤษบางชุด ภาษาไทยจึงถูกแปลงเป็นรหัส % เช่น เว็บไซต์ → %E0%B9%80%E0%B8%A7%E0%B9%87%E0%B8%9A%E0%B9%84%E0%B8%8B%E0%B8%95%E0%B9%8C (ลองคัดลอก URL ภาษาไทยจากแถบที่อยู่ไปวางดู) · ช่องว่างกลายเป็น %20 (หรือ + เฉพาะใน query string ที่มาจากฟอร์ม)

Punycode: โดเมนภาษาไทย .ไทย จริง ๆ แล้วถูกเก็บในระบบ DNS เป็น xn--o3cw4h และ เว็บ.ไทย = xn--r3cz4e3a.xn--o3cw4h

ตั้งชื่อไฟล์/โฟลเดอร์เว็บ: อังกฤษตัวพิมพ์เล็ก ไม่เว้นวรรค ใช้ - เช่น contact-us.html — ใช้ - ดีกว่า _ เพราะ Google มองขีดกลางเป็นตัวคั่นคำ (ดีต่อ SEO)

www ไม่ใช่ส่วนบังคับ! เป็นแค่ซับโดเมนที่นิยมตั้งในยุคแรกเพื่อบอกว่า “เครื่องนี้ให้บริการเว็บ” ปัจจุบันหลายเว็บตั้งให้ www redirect ไปโดเมนหลัก (หรือกลับกัน)

05

IP Address & Port

“บ้านเลขที่” และ “ประตู” — ต้องเข้าใจก่อนจะตั้งค่าโดเมนและเซิร์ฟเวอร์ของตัวเองในหน่วยที่ 5

IPv4

32 บิต เขียนเป็นเลข 4 ชุด ชุดละ 0–255 เช่น 203.0.113.10 · มีได้ราว 4,300 ล้าน หมายเลข → ไม่พอใช้แล้ว!

IPv6

128 บิต เลขฐาน 16 เช่น 2001:db8::1 · มีได้ 3.4×1038 หมายเลข (มากพอให้ทรายทุกเม็ดบนโลกมี IP)

Public IP vs Private IP

Public ใช้บนอินเทอร์เน็ต ไม่ซ้ำทั้งโลก (เซิร์ฟเวอร์ของเราต้องมี) · Private ใช้ในวง LAN: 192.168.x.x 10.x.x.x 172.16–31.x.x · Router ใช้ NAT แปลงให้หลายเครื่องใช้ Public IP เดียวกัน

Localhost

127.0.0.1 (หรือชื่อ localhost) = “เครื่องตัวเอง” ข้อมูลไม่ออกนอกเครื่องเลย — ใช้ตอนพัฒนาเว็บด้วย XAMPP/Live Server (หน่วยที่ 3)

Port ที่นักพัฒนาเว็บต้องรู้

Portบริการใช้ทำอะไรในวิชานี้
80HTTPเว็บแบบไม่เข้ารหัส (ควร redirect ไป 443)
443HTTPSเว็บแบบเข้ารหัส — มาตรฐานปัจจุบัน
22SSH / SFTPควบคุมเซิร์ฟเวอร์และอัปโหลดไฟล์อย่างปลอดภัย (หน่วยที่ 5)
21FTPอัปโหลดไฟล์แบบเก่า ไม่เข้ารหัส (ไม่แนะนำ)
53DNSถาม-ตอบชื่อโดเมน
3306MySQL/MariaDBฐานข้อมูลของ WordPress (ไม่ควรเปิดสู่อินเทอร์เน็ต)
8080 5500 3000พอร์ตทางเลือกเซิร์ฟเวอร์ทดสอบตอนพัฒนา

อยากรู้ IP ของตัวเอง: Private IP พิมพ์ ipconfig (Windows) หรือ ip a (Linux) · Public IP เปิดเว็บ ifconfig.me หรือ curl ifconfig.me

ทำไมเลข IP แต่ละชุดไม่เกิน 255? เพราะแต่ละชุดคือ 8 บิต (1 ไบต์) → 28 = 256 ค่า (0–255) · IPv4 จึงมี 4 × 8 = 32 บิต

06

DNS: สมุดโทรศัพท์ของอินเทอร์เน็ต

คนจำชื่อ — คอมพิวเตอร์จำตัวเลข · DNS แปลงให้

DNS Record ที่ต้องใช้จริงในหน่วยที่ 5

ชนิดหน้าที่ตัวอย่าง
Aชื่อ → IPv4@ → 203.0.113.50 · student01 → 203.0.113.50
AAAAชื่อ → IPv6@ → 2001:db8::50
CNAMEชื่อเล่น ชี้ไปอีกชื่อหนึ่งwww → example.ac.th
MXเซิร์ฟเวอร์รับอีเมลของโดเมน@ → mail.example.ac.th (priority 10)
TXTข้อความยืนยัน/นโยบายยืนยัน Google Search Console, SPF อีเมล
NSบอกว่าใครดูแล DNS ของโดเมนนี้ns1.provider.com

ทั้งโลกมี Root Server แค่ 13 ชื่อ (a.root-servers.net ถึง m) แต่แต่ละชื่อมีเครื่องจริงกระจายอยู่ทั่วโลกรวมกว่า 1,000 จุดด้วยเทคนิค Anycast — มีในประเทศไทยด้วย

ไฟล์ hosts คือ “DNS ส่วนตัว” ที่เครื่องอ่านก่อนถาม DNS จริง · Windows: C:\Windows\System32\drivers\etc\hosts · Linux/macOS: /etc/hosts — ใช้ทดสอบโดเมนก่อนย้ายเซิร์ฟเวอร์ได้ เช่นเพิ่มบรรทัด 203.0.113.50 student01.example.ac.th

ดู DNS cache ของ Chrome: chrome://net-internals/#dns · ล้าง DNS cache ของ Windows: ipconfig /flushdns — ใช้เมื่อเพิ่งแก้ DNS แล้วเครื่องยังไปที่เก่า

CNAME ใช้กับโดเมนหลัก (@) ไม่ได้ ตามมาตรฐาน DNS เพราะชนกับ record อื่น เช่น NS/MX · โดเมนหลักต้องใช้ A record

HTTP/1.1 → HTTP/2 → HTTP/3: HTTP/2 ส่งหลายไฟล์พร้อมกันในการเชื่อมต่อเดียว (multiplexing) · HTTP/3 วิ่งบน QUIC ซึ่งใช้ UDP แทน TCP ทำให้เชื่อมต่อเร็วขึ้นและทนต่อเน็ตมือถือที่สลับเสาสัญญาณ — ดูได้ใน DevTools คอลัมน์ Protocol (h2, h3)

CDN (Content Delivery Network) เช่น Cloudflare เก็บสำเนาไฟล์เว็บไว้ใกล้ผู้ใช้ทั่วโลก ผู้ใช้ในไทยจึงโหลดจากเครื่องในไทยแทนต่างประเทศ → เร็วขึ้นมาก และช่วยกันการโจมตี DDoS

เวลา “เว็บไม่ขึ้น” ให้ไล่ทีละขั้น: DNS หาไม่เจอ (DNS_PROBE_FINISHED_NXDOMAIN — ชื่อผิด/โดเมนหมดอายุ) · เชื่อมต่อไม่ได้ (ERR_CONNECTION_REFUSED — เซิร์ฟเวอร์/พอร์ตปิด) · 404 ไฟล์ไม่มี · 500 โค้ดฝั่งเซิร์ฟเวอร์พัง

HTTP Request & Response

“จดหมาย” ระหว่างเบราว์เซอร์กับเซิร์ฟเวอร์ — หน้าตาจริงเป็นแบบนี้

Methodความหมาย
GETขอดูข้อมูล (ข้อมูลอยู่ใน URL)
POSTส่งข้อมูลใหม่ (อยู่ใน Body) เช่น ล็อกอิน ฟอร์ม
PUT / PATCHแก้ไขข้อมูล
DELETEลบข้อมูล
HEADขอเฉพาะ Header (ใช้ curl -I)
Headerหน้าที่
Content-Typeชนิดข้อมูล เช่น text/html, image/webp
Cache-Controlให้เบราว์เซอร์เก็บไฟล์ไว้นานแค่ไหน
Locationที่อยู่ใหม่ (ใช้คู่กับ 301/302)
Set-Cookieฝากข้อมูลเล็ก ๆ ไว้ที่เบราว์เซอร์
Strict-Transport-Securityบังคับใช้ HTTPS เสมอ (HSTS)

HTTP เป็น Stateless — เซิร์ฟเวอร์ “จำไม่ได้” ว่าคำขอก่อนหน้าเป็นใคร เว็บจึงใช้ Cookie + Session: หลังล็อกอิน เซิร์ฟเวอร์ส่ง Set-Cookie: session=… แล้วเบราว์เซอร์แนบ Cookie นี้กลับไปทุกครั้ง เซิร์ฟเวอร์จึงรู้ว่าเป็นคนเดิม

ดู Header ของเว็บไหนก็ได้ใน 1 บรรทัด: curl -I https://www.google.com (มีใน Windows 10/11 แล้ว) — จะเห็น Status, Server, Content-Type, Cache-Control ทันที

HTTP vs HTTPS: ทำไมต้องมีกุญแจ 🔒

ดูว่าคนดักฟัง Wi-Fi สาธารณะเห็นอะไรบ้าง

คลิกรูปกุญแจที่แถบที่อยู่ → “การเชื่อมต่อปลอดภัย” → “ใบรับรองถูกต้อง” จะเห็นว่าใครออกใบรับรอง (เช่น Let's Encrypt, DigiCert) และ วันหมดอายุ

Let's Encrypt แจกใบรับรอง ฟรี ทำให้ HTTPS กลายเป็นมาตรฐาน ใบรับรองมีอายุสั้น (ราว 90 วัน และมีแผนสั้นลงอีก) จึงต้องตั้ง ต่ออายุอัตโนมัติ — certbot ทำให้เอง

HTTPS แปลว่า “ข้อมูลระหว่างทางปลอดภัย” ไม่ได้แปลว่าเว็บนั้นน่าเชื่อถือ — เว็บหลอกลวง (Phishing) ก็มีกุญแจได้ ต้องดูชื่อโดเมนให้ดีเสมอ

แบบผสม (Hybrid)

แบบทดสอบ หน่วยที่ 1

12 ข้อ · เฉลยทันที

ข้อใดอธิบายความสัมพันธ์ของ Internet กับ WWW ได้ถูกต้อง

Internet = โครงสร้างเครือข่าย (ถนน) · WWW = บริการเอกสารเว็บที่วิ่งบนเครือข่าย

ใน https://shop.example.co.th/products/list.html?cat=shirt#top ส่วนใดคือ Path

Path คือตำแหน่งโฟลเดอร์/ไฟล์ต่อจากชื่อโดเมน

IP ใดเป็น Private IP ที่ใช้ภายใน LAN

ช่วง Private: 192.168.x.x, 10.x.x.x, 172.16–31.x.x

ต้องการให้ student01.example.ac.th ชี้ไปที่ IP ของเซิร์ฟเวอร์ ควรสร้าง DNS record ชนิดใด

A record แปลงชื่อเป็น IPv4 · MX ใช้กับอีเมล

อัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์อย่างปลอดภัยด้วย SFTP ใช้พอร์ตใด

SFTP ทำงานบน SSH พอร์ต 22 · FTP (21) ไม่เข้ารหัส

เรียงลำดับ: (ก) HTTP Request (ข) DNS (ค) Render (ง) TCP/TLS

ต้องรู้ IP (DNS) → เชื่อมต่อ (TCP/TLS) → ขอข้อมูล (HTTP) → วาด (Render)

หลัง Deploy เว็บแล้วเข้าไม่ได้ ขึ้น 403 Forbidden สาเหตุที่น่าจะเป็นที่สุดคือ

403 = เซิร์ฟเวอร์ไม่อนุญาตให้อ่าน · ถ้า DNS ผิดจะเข้าไม่ถึงเซิร์ฟเวอร์เลย · บั๊ก PHP = 500

เหตุใด HTTP จึงต้องใช้ Cookie/Session ในการจำผู้ใช้ที่ล็อกอิน

แต่ละ Request เป็นอิสระ จึงต้องแนบ Cookie เพื่อบอกว่าเป็นใคร

ในการ Render ข้อใดคือขั้น “คำนวณตำแหน่งและขนาดของทุกกล่อง”

Layout (Reflow) คำนวณเรขาคณิต · Paint ลงสี · Composite รวมเลเยอร์

ข้อใดจับคู่ภาษากับหน้าที่ถูกต้อง

HTML โครงสร้าง · CSS หน้าตา · JS พฤติกรรม · PHP ทำงานฝั่งเซิร์ฟเวอร์

“LEMP stack” ประกอบด้วยอะไร

E มาจากการอ่าน Nginx ว่า “Engine-x”

ขั้นใดของ WDLC ที่ผลลัพธ์คือ Sitemap, Wireframe และ Mockup

สรุป หน่วยที่ 1

ภาพใหญ่ในประโยคเดียว: “ถามที่อยู่ → เคาะประตู → ขอของ → ได้ของ → ประกอบร่าง”

  • Internet = เครือข่ายของเครือข่าย (TCP/IP, IP, Port) · WWW = บริการเอกสารบนอินเทอร์เน็ต (HTML + HTTP + URL)
  • URL 8 ส่วน · DNS แปลงชื่อเป็น IP ด้วย Record (A, CNAME, MX, TXT, NS) และ Cache ตาม TTL
  • ลำดับ: DNS → TCP/TLS → HTTP Request → ประมวลผล → Response → ไฟล์ประกอบ → Render (DOM, CSSOM, Layout, Paint, Composite)
  • HTTP Method · Header · Status (2xx/3xx/4xx/5xx) · Stateless → Cookie · HTTPS = TLS + Certificate
  • HTML/CSS/JS · Frontend/Backend/Database/Server · Static vs Dynamic · โครงสร้างเว็บ 4 แบบ
  • WDLC 7 ขั้น = แผนที่ของ 5 หน่วยในรายวิชานี้
