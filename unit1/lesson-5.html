เครื่องมือ & เว็บเพจแรกของฉัน

ถึงเวลาลงมือจริง! ครั้งนี้รู้จักเครื่องมือของนักพัฒนาเว็บ ดูว่าโค้ดที่เราพิมพ์กลายเป็นหน้าเว็บได้อย่างไร เข้าใจโครงสร้างไฟล์ HTML ทีละบรรทัด แล้วสร้างเว็บเพจแนะนำตัวเองเป็นชิ้นงานแรกของวิชา

ในบทนี้
จุดประสงค์ เครื่องมือนักพัฒนาเว็บ จากโค้ดสู่หน้าจอ เตรียมเครื่อง & โฟลเดอร์ กายวิภาคของแท็ก โครงสร้างไฟล์ HTML แท็กพื้นฐาน ลองเขียนสด ใบงาน 1.5 แบบทดสอบ ทดสอบหลังเรียนหน่วย สรุปหน่วยที่ 1
01

จุดประสงค์การเรียนรู้

หลังเรียนครั้งนี้ ผู้เรียนสามารถ…

  1. บอกเครื่องมือที่ใช้ในการพัฒนาเว็บไซต์และหน้าที่ของแต่ละเครื่องมือได้
  2. อธิบายขั้นตอนที่เบราว์เซอร์เปลี่ยนโค้ด HTML เป็นหน้าเว็บได้
  3. ระบุส่วนประกอบของแท็ก HTML (แท็กเปิด แอตทริบิวต์ เนื้อหา แท็กปิด) ได้
  4. เขียนโครงสร้างเอกสาร HTML ที่ถูกต้องและแสดงภาษาไทยได้
  5. สร้างเว็บเพจแนะนำตนเองด้วยแท็กพื้นฐาน ตั้งชื่อไฟล์และโฟลเดอร์ถูกหลัก
02

เครื่องมือของนักพัฒนาเว็บ

กล่องเครื่องมือที่ใช้ตลอดทั้งรายวิชา (ส่วนใหญ่ฟรี!)

Text / Code Editor

VS Code (แนะนำ), Notepad++ — พิมพ์โค้ด มีสีแยกคำสั่ง เติมโค้ดอัตโนมัติ

Web Browser

Chrome, Edge, Firefox — เปิดดูผลลัพธ์ และทดสอบหลายเบราว์เซอร์

DevTools

กด F12 ในเบราว์เซอร์ — ส่องโค้ด ดู Network แก้ CSS สด จำลองมือถือ

Web Server จำลอง

Live Server (ส่วนขยาย VS Code), XAMPP — ทำให้เครื่องเราเป็นเซิร์ฟเวอร์ (หน่วยที่ 4)

ออกแบบ / กราฟิก

Figma, Canva, Photopea — ทำ Wireframe, Mockup, ตกแต่งรูป

CMS

WordPress, Google Sites — สร้างเว็บแบบไม่ต้องเขียนโค้ดทั้งหมด (หน่วยที่ 6)

อัปโหลด

FileZilla (FTP), Git + GitHub Pages — นำเว็บขึ้นเซิร์ฟเวอร์จริง (หน่วยที่ 7)

ผู้ช่วย AI

ช่วยอธิบายโค้ดและหาข้อผิดพลาด — ใช้เพื่อ “เรียนรู้” ต้องเข้าใจและตรวจสอบโค้ดเองเสมอ

04

เตรียมเครื่อง & โฟลเดอร์งาน

ทำครั้งเดียว ใช้ได้ทั้งเทอม

ติดตั้ง VS Code + Live Server

  1. ดาวน์โหลด VS Code จาก code.visualstudio.com แล้วติดตั้ง (ติ๊ก “Add to PATH” และ “Open with Code”)
  2. เปิด VS Code → แถบซ้ายกดไอคอน Extensions (Ctrl+Shift+X)
  3. ค้นหา Live Server (ผู้พัฒนา Ritwick Dey) → Install
  4. (แนะนำ) ติดตั้ง Thai Language Pack ถ้าต้องการเมนูภาษาไทย
  5. File → Open Folder เลือกโฟลเดอร์งาน → คลิกขวาไฟล์ index.html → Open with Live Server

โครงสร้างโฟลเดอร์ที่ดี

📁 6701-somchai/        ← รหัส-ชื่อ
 ├─ 📄 index.html       ← หน้าแรก (ชื่อบังคับ)
 ├─ 📄 about.html
 ├─ 📁 css/
 │   └─ 📄 style.css
 └─ 📁 images/
     └─ 🖼️ profile.jpg

กฎการตั้งชื่อไฟล์เว็บ

  • ใช้ ภาษาอังกฤษตัวพิมพ์เล็ก ตัวเลข - หรือ _
  • ห้ามเว้นวรรค ห้ามภาษาไทย ห้ามอักขระพิเศษ ✗ หน้า แรก.html ✓ contact-us.html
  • หน้าแรกชื่อ index.html เสมอ (เซิร์ฟเวอร์เปิดให้อัตโนมัติ)

คีย์ลัด VS Code ที่ใช้บ่อย! + Tab สร้างโครง HTML ทันที (Emmet) · Ctrl+S บันทึก · Ctrl+/ ใส่/เอาคอมเมนต์ · Alt+Shift+F จัดย่อหน้าโค้ด · Alt+↑/↓ ย้ายบรรทัด

10

แบบทดสอบท้ายครั้งที่ 5

เลือกคำตอบเดียว

ส่วนใดของเอกสาร HTML ที่เนื้อหา “ไม่แสดง” บนหน้าเว็บ

<head> เก็บข้อมูลเกี่ยวกับหน้าเว็บ เช่น charset, title, ลิงก์ CSS ซึ่งไม่แสดงในพื้นที่หน้าเว็บ

หน้าเว็บแสดงภาษาไทยเป็นตัวอักษรแปลก ๆ น่าจะลืมใส่ข้อใด

charset UTF-8 กำหนดการเข้ารหัสอักขระที่รองรับภาษาไทย

ใน <img src="me.jpg" alt="รูปฉัน"> คำว่า src คืออะไร

src เป็นแอตทริบิวต์ (คุณสมบัติ) บอกที่อยู่ไฟล์รูป ส่วน img เป็นชื่อแท็ก

ชื่อไฟล์ใดถูกหลักการตั้งชื่อไฟล์เว็บมากที่สุด

ใช้ภาษาอังกฤษตัวพิมพ์เล็ก ไม่เว้นวรรค ใช้ - หรือ _ แทน

ขั้นตอนที่เบราว์เซอร์อ่านโค้ด HTML แล้วสร้างโครงสร้างแบบต้นไม้ เรียกว่าอะไร

เบราว์เซอร์ Parse โค้ดสร้าง DOM Tree ก่อน แล้วจึง Render วาดลงหน้าจอ

11

แบบทดสอบหลังเรียน หน่วยที่ 1

12 ข้อ ครอบคลุมทั้ง 5 ครั้ง · เกณฑ์ผ่าน 60% (8 ข้อขึ้นไป)

“เครือข่ายของเครือข่าย” หมายถึงข้อใด

อินเทอร์เน็ตเกิดจากการเชื่อมเครือข่ายจำนวนมากทั่วโลกเข้าด้วยกัน

ผู้คิดค้น World Wide Web คือใคร

Tim Berners-Lee ที่ CERN เสนอแนวคิด WWW ในปี 2532 (1989) พร้อม HTML, HTTP, URL

ใน URL https://www.example.ac.th/news.php?id=5 ส่วน ?id=5 คืออะไร

ส่วนที่ขึ้นต้นด้วย ? ใช้ส่งข้อมูลไปให้เซิร์ฟเวอร์ เรียกว่า Query string

ระบบใดทำหน้าที่แปลง www.example.ac.th เป็น 203.0.113.10

DNS = สมุดรายชื่อของอินเทอร์เน็ต

เมื่อเบราว์เซอร์ได้รับ HTML แล้ว ทำไมยังส่ง Request เพิ่มอีกหลายครั้ง

HTML อ้างถึงไฟล์อื่น เบราว์เซอร์จึงต้องขอไฟล์เหล่านั้นเพิ่มก่อนแสดงผลสมบูรณ์

Status code กลุ่ม 4xx หมายถึงอะไร

4xx เช่น 404 Not Found, 403 Forbidden เป็นปัญหาจากคำขอ

ข้อใดจับคู่ภาษากับหน้าที่ได้ถูกต้อง

HTML = โครงสร้าง · CSS = หน้าตา · JavaScript = การโต้ตอบ

เว็บร้านค้าออนไลน์ที่แสดงสินค้าในตะกร้าของแต่ละคนต่างกัน เป็นเว็บประเภทใด

Dynamic สร้างหน้าเว็บจากฐานข้อมูลตามผู้ใช้แต่ละคน

บทเรียนออนไลน์ที่ต้องเรียนหน้า 1 → 2 → 3 ตามลำดับ เหมาะกับโครงสร้างเว็บแบบใด

โครงสร้างเชิงเส้น (Linear) เรียงหน้าตามลำดับ

ขั้นตอนใดในกระบวนการพัฒนาเว็บไซต์ที่ทำ Wireframe และ Mockup

ขั้นออกแบบ (Design): Sitemap → Wireframe → Mockup

ข้อใดคือลำดับที่ถูกต้องของโค้ด HTML

DOCTYPE อยู่บรรทัดแรก ตามด้วย html ซึ่งครอบ head และ body ตามลำดับ

ข้อใดเป็นการซ้อนแท็กที่ถูกต้อง

แท็กที่เปิดทีหลังต้องปิดก่อน (เปิด p → เปิด b → ปิด b → ปิด p)

12

สรุปหน่วยที่ 1

จากสายเคเบิลใต้น้ำ สู่เว็บเพจแรกของเรา

  • ครั้งที่ 1 อินเทอร์เน็ต = เครือข่าย, WWW = บริการเอกสารบนเครือข่าย, URL มี 8 ส่วน
  • ครั้งที่ 2 Client–Server: DNS → TCP/TLS → HTTP Request → Response → Render · Status Code · HTTPS
  • ครั้งที่ 3 HTML/CSS/JS · Frontend/Backend/Database · Static/Dynamic · โครงสร้างเว็บ 4 แบบ · ส่วนประกอบหน้าเว็บ
  • ครั้งที่ 4 วงจรพัฒนาเว็บ 7 ขั้น · Sitemap → Wireframe → Mockup → Website · ทีมพัฒนาเว็บ
  • ครั้งที่ 5 เครื่องมือ · โค้ด → DOM → Render · กายวิภาคแท็ก · โครง HTML5 · เว็บเพจแรก
