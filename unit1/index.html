สมรรถนะประจำหน่วย

แสดงความรู้เกี่ยวกับหลักการ กระบวนการพัฒนา และโครงสร้างการทำงานของเว็บไซต์ และสร้างเว็บเพจพื้นฐานด้วยภาษา HTML ได้ตามหลักการ

สอดคล้องกับ สมรรถนะรายวิชาข้อ 1 และเป็นพื้นฐานของสมรรถนะข้อ 2

จุดประสงค์เชิงพฤติกรรม

  1. อธิบายความแตกต่างระหว่างอินเทอร์เน็ตกับเวิลด์ไวด์เว็บ และคำศัพท์พื้นฐานได้
  2. แยกส่วนประกอบของ URL และอธิบายหน้าที่ของแต่ละส่วนได้
  3. อธิบายลำดับการทำงานของเว็บ ตั้งแต่พิมพ์ URL จนแสดงผล (DNS → HTTP → Render) ได้
  4. จำแนกหน้าที่ของ HTML, CSS, JavaScript และเว็บแบบ Static/Dynamic ได้
  5. เขียนแผนผังโครงสร้างเว็บไซต์และระบุส่วนประกอบของหน้าเว็บได้
  6. เรียงลำดับและอธิบายขั้นตอนของกระบวนการพัฒนาเว็บไซต์ได้
  7. สร้างเว็บเพจแรกด้วย HTML ที่มีโครงสร้างถูกต้องได้
  8. ปฏิบัติงานด้วยความรับผิดชอบ ละเอียดรอบคอบ และทำงานร่วมกับผู้อื่นได้

ภาพรวมความคิดของหน่วยนี้

5 ครั้งต่อกันเป็นเรื่องเดียว

  1. ครั้งที่ 1 · “เว็บอยู่ที่ไหน?”

    อินเทอร์เน็ต = ถนน, เว็บ = บริการหนึ่งที่วิ่งบนถนนนั้น, URL = ที่อยู่ของสิ่งที่เราอยากได้

  2. ครั้งที่ 2 · “เว็บมาถึงเครื่องเราได้ยังไง?”

    Browser ถาม DNS หา IP → ส่ง HTTP Request → Server ตอบ Response → Browser วาดหน้าเว็บ

  3. ครั้งที่ 3 · “ข้างในเว็บมีอะไร?”

    HTML (โครง) + CSS (หน้าตา) + JS (การโต้ตอบ), หน้าบ้าน/หลังบ้าน, การจัดโครงสร้างหน้าต่าง ๆ

  4. ครั้งที่ 4 · “มืออาชีพสร้างเว็บกันยังไง?”

    วางแผน → วิเคราะห์ → ออกแบบ → พัฒนา → ทดสอบ → เผยแพร่ → ดูแลรักษา (ซึ่งก็คือหน่วยที่ 2–7 ของวิชานี้!)

  5. ครั้งที่ 5 · “ลงมือทำเลย!”

    เตรียมเครื่องมือ เข้าใจว่าโค้ดกลายเป็นหน้าจอได้อย่างไร แล้วเขียนเว็บเพจแรกของตัวเอง
