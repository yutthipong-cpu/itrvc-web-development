อินเทอร์เน็ต & เวิลด์ไวด์เว็บ

เราใช้เว็บทุกวัน แต่รู้ไหมว่า “อินเทอร์เน็ต” กับ “เว็บ” ไม่ใช่สิ่งเดียวกัน! ครั้งนี้จะดูว่าเครือข่ายคอมพิวเตอร์ทั้งโลกต่อกันได้อย่างไร คำศัพท์ที่นักพัฒนาเว็บต้องรู้ และผ่า URL ออกมาดูทีละชิ้น

ในบทนี้
จุดประสงค์ อินเทอร์เน็ตคืออะไร ประวัติย่อ อินเทอร์เน็ต vs เว็บ คำศัพท์ต้องรู้ ผ่า URL ประเภทเว็บไซต์ ยุคของเว็บ ใบงาน 1.1 แบบทดสอบ สรุป
01

จุดประสงค์การเรียนรู้

หลังเรียนครั้งนี้ ผู้เรียนสามารถ…

  1. อธิบายความหมายและการทำงานพื้นฐานของเครือข่ายอินเทอร์เน็ตได้
  2. บอกความแตกต่างระหว่างอินเทอร์เน็ต (Internet) กับเวิลด์ไวด์เว็บ (WWW) ได้
  3. อธิบายคำศัพท์พื้นฐาน เช่น เว็บเพจ เว็บไซต์ โฮมเพจ เบราว์เซอร์ เว็บเซิร์ฟเวอร์ โดเมนเนม ได้
  4. แยกส่วนประกอบของ URL และบอกหน้าที่ของแต่ละส่วนได้
  5. จำแนกประเภทของเว็บไซต์ตามวัตถุประสงค์การใช้งานได้

อุ่นเครื่องก่อนเรียน (5 นาที)ให้นักเรียนเขียนลงกระดาษว่า “เช้านี้ใช้อินเทอร์เน็ตทำอะไรไปแล้วบ้าง?” แล้วลองแยกดูว่าอันไหนเป็น “เว็บ” อันไหน “ไม่ใช่เว็บ” — เฉลยอยู่ในหัวข้อที่ 4

02

อินเทอร์เน็ตคืออะไร?

ดูแอนิเมชันว่าคอมพิวเตอร์ 1 เครื่อง กลายเป็นเครือข่ายทั้งโลกได้อย่างไร

อินเทอร์เน็ต (Internet) ย่อมาจาก Inter-connected Network คือ เครือข่ายคอมพิวเตอร์ขนาดใหญ่ที่สุดในโลก เกิดจากการนำเครือข่ายเล็ก ๆ จำนวนมหาศาลมาเชื่อมต่อกัน จึงมักเรียกว่า “เครือข่ายของเครือข่าย” (Network of Networks) ทุกเครื่องคุยกันได้เพราะใช้ “ภาษากลาง” เดียวกันชื่อว่า TCP/IP และทุกเครื่องมีเลขประจำตัวเรียกว่า IP Address (เช่น 203.0.113.10)

03

ประวัติย่อ: จาก ARPANET ถึงเว็บบนมือถือ

จำปีไม่ต้องเป๊ะ แต่ให้เข้าใจลำดับเหตุการณ์

  1. พ.ศ. 2512 (1969) · ARPANET

    กระทรวงกลาโหมสหรัฐฯ เชื่อมคอมพิวเตอร์ 4 มหาวิทยาลัยเข้าด้วยกัน — จุดเริ่มต้นของอินเทอร์เน็ต

  2. พ.ศ. 2526 (1983) · TCP/IP

    เครือข่ายเปลี่ยนมาใช้โปรโตคอล TCP/IP ซึ่งยังเป็นภาษากลางของอินเทอร์เน็ตมาจนถึงทุกวันนี้

  3. พ.ศ. 2532 (1989) · กำเนิดแนวคิด WWW

    Tim Berners-Lee นักวิทยาศาสตร์ที่ CERN เสนอระบบเอกสารที่เชื่อมโยงกันด้วยลิงก์ ประกอบด้วย 3 สิ่งที่เรายังใช้อยู่: HTML · HTTP · URL

  4. พ.ศ. 2534 (1991) · เว็บไซต์แรกของโลก

    info.cern.ch ออนไลน์ เป็นหน้าเว็บตัวอักษรล้วน อธิบายว่า WWW คืออะไร

  5. พ.ศ. 2535 (1992) · ประเทศไทยเชื่อมอินเทอร์เน็ต

    มหาวิทยาลัยในไทยเริ่มเชื่อมต่ออินเทอร์เน็ตแบบถาวรกับต่างประเทศ (ความเร็วเพียงประมาณ 9.6 kbps)

  6. พ.ศ. 2536 (1993) · เบราว์เซอร์ Mosaic

    แสดงรูปภาพร่วมกับข้อความได้ ทำให้เว็บใช้ง่ายและได้รับความนิยมอย่างรวดเร็ว

  7. พ.ศ. 2547–2550 · ยุคโซเชียลและสมาร์ตโฟน

    Facebook, YouTube เกิดขึ้น และ iPhone ทำให้คนท่องเว็บบนมือถือ → เว็บต้องรองรับทุกขนาดหน้าจอ

  8. ปัจจุบัน · Cloud & AI

    เว็บกลายเป็น “แอปพลิเคชัน” เต็มรูปแบบ ทำงานบนคลาวด์ เชื่อมกับ AI และใช้งานได้ทุกอุปกรณ์

04

อินเทอร์เน็ต ≠ เว็บ

คำที่คนทั่วไปใช้แทนกัน แต่ความจริงคนละอย่าง

Internet (อินเทอร์เน็ต)

  • คือ โครงสร้างพื้นฐาน — สาย อุปกรณ์ เครือข่าย
  • เกิดก่อน (พ.ศ. 2512)
  • เปรียบเหมือน ถนน
  • มีหลายบริการ: Email, Video Call, Game, File Transfer (FTP), WWW
VS

WWW (เวิลด์ไวด์เว็บ)

  • คือ บริการหนึ่ง บนอินเทอร์เน็ต
  • เกิดทีหลัง (พ.ศ. 2532)
  • เปรียบเหมือน รถส่งเอกสาร ที่วิ่งบนถนน
  • เป็นเอกสาร (เว็บเพจ) ที่เชื่อมโยงกันด้วย ไฮเปอร์ลิงก์ เปิดดูด้วย เว็บเบราว์เซอร์ ผ่านโปรโตคอล HTTP

เฉลยกิจกรรมอุ่นเครื่องดู YouTube ผ่าน Chrome / อ่านข่าวในเว็บ / ค้นหา Google = ใช้ เว็บ · ส่งอีเมลผ่านแอป Mail, เล่นเกมออนไลน์, วิดีโอคอลใน LINE = ใช้ อินเทอร์เน็ต แต่ไม่ใช่เว็บ (เป็นบริการอื่น)

ประเภทของเว็บไซต์

แบ่งตามวัตถุประสงค์การใช้งาน — ก่อนสร้างเว็บต้องรู้ก่อนว่าเว็บเราอยู่ประเภทไหน

องค์กร / สถานศึกษา

ให้ข้อมูลหน่วยงาน ข่าวประชาสัมพันธ์ ติดต่อ เช่น เว็บวิทยาลัย เว็บบริษัท

พาณิชย์อิเล็กทรอนิกส์ (E-Commerce)

ซื้อขายสินค้าออนไลน์ มีตะกร้าและระบบชำระเงิน เช่น Shopee, Lazada

ข่าว / สารสนเทศ

นำเสนอข่าวและบทความที่อัปเดตบ่อย เช่น เว็บข่าว เว็บพยากรณ์อากาศ

เครือข่ายสังคม (Social)

ผู้ใช้สร้างเนื้อหาและสื่อสารกัน เช่น Facebook, X, TikTok

ค้นหา / ท่า (Portal)

รวบรวมลิงก์และข้อมูลจำนวนมาก เป็นประตูไปยังเว็บอื่น เช่น Google

การศึกษา (E-Learning)

บทเรียนออนไลน์ แบบทดสอบ ห้องเรียนเสมือน เช่น Google Classroom, เว็บนี้!

ส่วนตัว / ผลงาน (Blog, Portfolio)

แนะนำตัว แสดงผลงาน เขียนบทความ — งานที่นักเรียนจะได้ทำในวิชานี้

บันเทิง

วิดีโอ เพลง เกม เช่น YouTube, Netflix, Spotify

เว็บแอปพลิเคชัน / บริการ

ใช้งานเหมือนโปรแกรม เช่น ระบบทะเบียน ระบบจองห้อง Google Docs

08

ยุคของเว็บ: Web 1.0 → 2.0 → 3.0

เว็บเปลี่ยนจาก “อ่านอย่างเดียว” เป็น “มีส่วนร่วม” และ “ฉลาดขึ้น”

Web 1.0 — Read only (ประมาณ 2534–2547)

เจ้าของเว็บเขียน ผู้ใช้ได้แค่ อ่าน หน้าเว็บส่วนใหญ่เป็น Static (หน้าตาตายตัว) ข้อความ + รูปภาพ อัปเดตไม่บ่อย

ตัวอย่าง: เว็บไซต์ประชาสัมพันธ์บริษัทยุคแรก, เว็บไดเรกทอรี

Web 2.0 — Read & Write (ประมาณ 2547–ปัจจุบัน)

ผู้ใช้ สร้างเนื้อหาเอง ได้ (User-Generated Content) คอมเมนต์ แชร์ อัปโหลด เว็บเป็นแบบ Dynamic และรองรับมือถือ

ตัวอย่าง: Facebook, YouTube, Wikipedia, Blog

Web 3.0 — Read, Write & Own / Intelligent

เว็บที่ เข้าใจความหมายของข้อมูล (Semantic Web) ใช้ AI แนะนำเนื้อหาให้แต่ละคน และแนวคิดเครือข่ายแบบกระจายศูนย์ที่ผู้ใช้เป็นเจ้าของข้อมูล

ตัวอย่าง: ผู้ช่วย AI, ระบบแนะนำสินค้า/วิดีโออัตโนมัติ

แบบทดสอบท้ายครั้งที่ 1

เลือกคำตอบเดียว ระบบจะเฉลยและอธิบายทันที

ข้อใดอธิบายความสัมพันธ์ระหว่างอินเทอร์เน็ตกับ WWW ได้ถูกต้องที่สุด

อินเทอร์เน็ตคือโครงสร้างเครือข่าย (ถนน) ส่วน WWW คือบริการเอกสารเว็บที่วิ่งบนเครือข่ายนั้น และเกิดทีหลัง (2532)

“กลุ่มของเว็บเพจหลายหน้าที่เชื่อมโยงกันภายใต้โดเมนเดียวกัน” คือข้อใด

เว็บเพจ = 1 หน้า · เว็บไซต์ = หลายหน้ารวมกัน · โฮมเพจ = หน้าแรกของเว็บไซต์

ใน URL https://shop.example.co.th/products/list.html?cat=shirt#top ส่วนใดคือ Path

Path คือตำแหน่งโฟลเดอร์/ไฟล์บนเซิร์ฟเวอร์ ต่อจากชื่อโดเมน · shop = subdomain · ?cat=shirt = query string

เว็บไซต์ของวิทยาลัยเทคนิคในประเทศไทย ควรใช้โดเมนลงท้ายด้วยข้อใด

.ac.th (academic) สำหรับสถาบันการศึกษาในไทย · .co.th บริษัท · .go.th หน่วยงานรัฐ · .or.th องค์กร

ส่วนใดของ URL ที่ “ไม่ถูกส่งไป” ยังเว็บเซิร์ฟเวอร์

Fragment (#) ใช้ภายในเบราว์เซอร์เพื่อเลื่อนไปยังตำแหน่งในหน้า จึงไม่ส่งไปที่เซิร์ฟเวอร์

ผู้ใช้สามารถโพสต์ คอมเมนต์ และแชร์เนื้อหาได้เอง เป็นลักษณะเด่นของเว็บยุคใด

Web 2.0 คือยุคที่ผู้ใช้มีส่วนร่วมสร้างเนื้อหา (Read & Write) เช่น Facebook, YouTube

สรุปครั้งที่ 1

จำ 5 ข้อนี้ไว้ ใช้ต่อในครั้งหน้า

  • อินเทอร์เน็ต = เครือข่ายของเครือข่าย เชื่อมด้วย ISP ทั่วโลก คุยกันด้วย TCP/IP และระบุเครื่องด้วย IP Address
  • WWW = บริการเอกสารที่เชื่อมด้วยไฮเปอร์ลิงก์ เป็นแค่หนึ่งในบริการบนอินเทอร์เน็ต สร้างจาก HTML + HTTP + URL
  • เว็บเพจ 1 หน้า → หลายหน้ารวมเป็น เว็บไซต์ → หน้าแรกคือ โฮมเพจ · ดูด้วย เบราว์เซอร์ · เก็บไว้ที่ เว็บเซิร์ฟเวอร์
  • URL = Protocol + Subdomain + Domain + TLD + Port + Path + Query + Fragment
  • เว็บไซต์มีหลาย ประเภท ตามวัตถุประสงค์ ต้องรู้ประเภทก่อนจึงจะออกแบบได้ตรงใจผู้ใช้

คำถามชวนคิดสำหรับครั้งหน้าเราพิมพ์แค่ www.google.com แต่คอมพิวเตอร์รู้ได้อย่างไรว่าต้องไปหาเครื่องไหน ในเมื่อคอมพิวเตอร์รู้จักแต่ “ตัวเลข IP”? 🤔
