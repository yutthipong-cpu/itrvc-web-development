โครงสร้าง & องค์ประกอบของเว็บไซต์

ครั้งที่แล้วเราเห็นว่าเซิร์ฟเวอร์ส่ง HTML, CSS, JS กลับมา ครั้งนี้จะ “ผ่า” ดูว่าแต่ละส่วนทำหน้าที่อะไร หน้าบ้าน–หลังบ้านต่างกันอย่างไร เว็บแบบ Static กับ Dynamic ทำงานต่างกันตรงไหน และจะจัดโครงสร้างหน้าเว็บหลาย ๆ หน้าให้เป็นระเบียบได้อย่างไร

ในบทนี้
จุดประสงค์ HTML + CSS + JS หน้าบ้าน / หลังบ้าน Static vs Dynamic โครงสร้างเว็บไซต์ 4 แบบ ส่วนประกอบหน้าเว็บ เว็บไซต์ที่ดี ใบงาน 1.3 แบบทดสอบ สรุป
01

จุดประสงค์การเรียนรู้

หลังเรียนครั้งนี้ ผู้เรียนสามารถ…

  1. อธิบายหน้าที่ของ HTML, CSS และ JavaScript ในหน้าเว็บได้
  2. จำแนกเทคโนโลยีฝั่ง Frontend, Backend และ Database ได้
  3. เปรียบเทียบการทำงานของเว็บไซต์แบบ Static และ Dynamic ได้
  4. อธิบายและเขียนแผนผังโครงสร้างเว็บไซต์ (Sitemap) ทั้ง 4 แบบได้
  5. ระบุส่วนประกอบหลักของหน้าเว็บเพจได้
02

HTML + CSS + JavaScript = หน้าเว็บ

สามภาษาหลักของฝั่งเบราว์เซอร์ แต่ละตัวมีหน้าที่ของตัวเอง

🧱

🎨
CSS =

03

หน้าบ้าน (Frontend) · หลังบ้าน (Backend) · ฐานข้อมูล

เว็บสมัยใหม่แบ่งเป็น 3 ชั้น เหมือนร้านอาหาร: หน้าร้าน – ครัว – ห้องเก็บของ

Frontend (ฝั่งผู้ใช้)

ส่วนที่ผู้ใช้ มองเห็นและโต้ตอบ ทำงานในเบราว์เซอร์

เทคโนโลยี: HTML, CSS, JavaScript, Bootstrap, Tailwind, React, Vue

อาชีพ: Frontend Developer, UI Designer

Backend (ฝั่งเซิร์ฟเวอร์)

ส่วน ประมวลผลเบื้องหลัง ที่ผู้ใช้มองไม่เห็น เช่น ตรวจรหัสผ่าน คำนวณเกรด

เทคโนโลยี: PHP, Node.js, Python, Java · เว็บเซิร์ฟเวอร์ Apache, Nginx

อาชีพ: Backend Developer

Database (ฐานข้อมูล)

ที่ เก็บข้อมูลอย่างเป็นระบบ เช่น ข้อมูลนักเรียน สินค้า โพสต์

เทคโนโลยี: MySQL/MariaDB, PostgreSQL, MongoDB, Firebase

อาชีพ: Database Administrator

Full-Stack Developerคือคนที่ทำได้ทั้ง Frontend และ Backend · ในวิชานี้เราจะเน้น Frontend (หน่วย 5) และใช้ CMS (หน่วย 6) ที่มี Backend + Database สำเร็จรูปมาให้แล้ว

เว็บไซต์ Static vs Dynamic

“ไฟล์สำเร็จรูป” กับ “ปรุงสดตามออเดอร์”

หัวข้อStatic WebsiteDynamic Website

การแก้ไขเนื้อหาต้องแก้ไฟล์โค้ดแก้ผ่านระบบหลังบ้าน (Admin)

05

โครงสร้างเว็บไซต์ (Site Structure) 4 แบบ

การจัดหน้าเว็บหลายหน้าให้เชื่อมกัน แสดงด้วย “แผนผังเว็บไซต์ (Sitemap)”

โครงสร้างแบบเชิงเส้น (Linear / Sequential)

หน้าเว็บเรียงต่อกัน ตามลำดับ ไปข้างหน้า–ย้อนกลับทีละหน้า เหมือนอ่านหนังสือ

เหมาะกับ: บทเรียนออนไลน์ แบบทดสอบ ฟอร์มสมัครหลายขั้นตอน ขั้นตอนสั่งซื้อสินค้า · ข้อเสีย: ข้ามไปหน้าที่ต้องการโดยตรงไม่ได้ ถ้ามีหลายหน้าจะน่าเบื่อ

โครงสร้างแบบลำดับชั้น (Hierarchical / Tree)

แบ่งเป็น หมวดหมู่ใหญ่ → หมวดย่อย เหมือนต้นไม้กลับหัว เริ่มจากโฮมเพจแตกแขนงลงไป ใช้มากที่สุด

เหมาะกับ: เว็บองค์กร เว็บวิทยาลัย เว็บหน่วยงาน · ข้อดี: เป็นระเบียบ ผู้ใช้เข้าใจง่าย · ข้อควรระวัง: ไม่ควรลึกเกิน 3 ระดับ (กฎ 3 คลิก)

โครงสร้างแบบเครือข่าย (Network / Webbed)

ทุกหน้า ลิงก์ถึงกันได้อย่างอิสระ ไม่มีลำดับตายตัว ผู้ใช้เลือกเส้นทางเอง

เหมาะกับ: สารานุกรม (Wikipedia) เว็บความรู้ที่เนื้อหาเกี่ยวโยงกัน · ข้อเสีย: ผู้ใช้ “หลงทาง” ได้ง่าย ดูแลยาก

โครงสร้างแบบผสม (Hybrid)

นำหลายแบบมารวมกัน: โครงหลักเป็น ลำดับชั้น บางส่วนเป็น เชิงเส้น (เช่น ขั้นตอนสมัครเรียน 1→2→3) และมี ลิงก์ข้ามหมวด (เส้นโค้ง) ระหว่างหน้าที่เกี่ยวข้องกัน

เหมาะกับ: เว็บไซต์ส่วนใหญ่ในชีวิตจริง เช่น เว็บวิทยาลัย ร้านค้าออนไลน์

06

ส่วนประกอบของหน้าเว็บเพจ

ไม่ว่าเว็บไหน ๆ ก็มักมีบล็อกเหล่านี้ · ดูการประกอบร่าง และการจัดใหม่บนมือถือ

07

องค์ประกอบของเว็บไซต์ที่ดี

ใช้เป็นเช็กลิสต์ทุกครั้งที่ออกแบบหรือประเมินเว็บไซต์

เนื้อหามีคุณภาพ

ถูกต้อง ทันสมัย ตรงความต้องการผู้ใช้ อ่านง่าย

นำทางชัดเจน

เมนูเข้าใจง่าย อยู่ที่เดิม รู้ว่าตอนนี้อยู่หน้าไหน

ออกแบบสม่ำเสมอ

สี ฟอนต์ ตำแหน่งเมนูเหมือนกันทุกหน้า

โหลดเร็ว

รูปภาพย่อขนาด โค้ดกระชับ ไม่เกิน 3 วินาที

รองรับทุกอุปกรณ์

Responsive แสดงผลดีทั้งคอม แท็บเล็ต มือถือ

เข้าถึงได้ทุกคน

ตัวอักษรอ่านง่าย สีตัดกันชัด รูปมีคำอธิบาย

ปลอดภัย น่าเชื่อถือ

ใช้ HTTPS มีข้อมูลติดต่อ ไม่มีลิงก์เสีย

อัปเดตสม่ำเสมอ

ข่าวไม่ค้าง ข้อมูลไม่หมดอายุ

09

แบบทดสอบท้ายครั้งที่ 3

เลือกคำตอบเดียว

ถ้าต้องการเปลี่ยน “สีและฟอนต์” ของหน้าเว็บ ต้องแก้ไขที่ภาษาใด

CSS รับผิดชอบการนำเสนอ/หน้าตา เช่น สี ฟอนต์ ขนาด การจัดวาง

ปุ่ม “เพิ่มลงตะกร้า” ที่กดแล้วตัวเลขบนไอคอนตะกร้าเพิ่มขึ้นทันที ใช้ภาษาใดเป็นหลัก

การตอบสนองต่อการกระทำของผู้ใช้ในหน้าเว็บเป็นหน้าที่ของ JavaScript

ข้อใดเป็นลักษณะของเว็บไซต์แบบ Dynamic

Dynamic สร้างหน้าเว็บใหม่ตามข้อมูลในฐานข้อมูลและผู้ใช้แต่ละคน

เว็บไซต์วิทยาลัยที่แบ่งเมนูเป็น เกี่ยวกับเรา / หลักสูตร / ข่าวสาร และแต่ละเมนูมีหน้าย่อย เป็นโครงสร้างแบบใด

แตกจากหมวดใหญ่ไปหมวดย่อยแบบต้นไม้ = ลำดับชั้น (Hierarchical)

ส่วนของหน้าเว็บที่มักมีที่อยู่ เบอร์โทร และข้อความลิขสิทธิ์ คือข้อใด

Footer อยู่ล่างสุดของหน้า ใช้แสดงข้อมูลติดต่อและลิขสิทธิ์

MySQL จัดอยู่ในส่วนใดของระบบเว็บ

MySQL คือระบบจัดการฐานข้อมูล ใช้เก็บข้อมูลของเว็บแบบ Dynamic

10

สรุปครั้งที่ 3

ข้างในเว็บไซต์มีอะไรบ้าง

  • HTML = โครงสร้าง · CSS = หน้าตา · JavaScript = การโต้ตอบ (ทั้งหมดทำงานในเบราว์เซอร์)
  • Frontend ส่วนที่ผู้ใช้เห็น · Backend ประมวลผลเบื้องหลัง · Database เก็บข้อมูล
  • Static ส่งไฟล์สำเร็จรูป ทุกคนเห็นเหมือนกัน · Dynamic สร้างหน้าใหม่จากฐานข้อมูลตามผู้ใช้
  • โครงสร้างเว็บไซต์ 4 แบบ: เชิงเส้น · ลำดับชั้น · เครือข่าย · ผสม แสดงด้วย Sitemap
  • หน้าเว็บทั่วไป: Header · Navigation · Banner · Content · Sidebar · Footer

คำถามชวนคิดสำหรับครั้งหน้าถ้าครูสั่งให้ทำเว็บไซต์แผนกวิชาภายใน 1 เดือน ควรเริ่มจากเปิดโปรแกรมเขียนโค้ดเลยหรือไม่? นักพัฒนามืออาชีพเริ่มต้นจากอะไร?
