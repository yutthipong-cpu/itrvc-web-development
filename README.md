# Web Dev · สื่อการเรียนรู้รายวิชา 31900-0001 การสร้างเว็บไซต์

เว็บไซต์สื่อการเรียนรู้แบบแอนิเมชัน ให้ผู้เรียน “เห็นหลังบ้าน” ของการทำงานของเว็บทีละขั้น
(ท1-ป4-น3 · หลักสูตร 2567 · 18 สัปดาห์ · 90 ชั่วโมง)

ตอนนี้เปิดให้เรียน **หน่วยที่ 1 หลักการและโครงสร้างการทำงานของเว็บไซต์** (5 ครั้ง)

## โครงสร้างไฟล์

```
index.html              หน้าแรก (เส้นทางการเรียนทั้งรายวิชา)
course.html             วิเคราะห์รายวิชา: หน่วย หัวข้อ แผนการสอน 18 สัปดาห์ การวัดผล
unit1/index.html        ภาพรวมหน่วยที่ 1 + ความก้าวหน้าของผู้เรียน
unit1/lesson-1.html     ครั้งที่ 1 อินเทอร์เน็ต & เวิลด์ไวด์เว็บ, ผ่า URL
unit1/lesson-2.html     ครั้งที่ 2 เว็บทำงานอย่างไร: Client–Server, DNS, HTTP, HTTPS
unit1/lesson-3.html     ครั้งที่ 3 โครงสร้าง & องค์ประกอบของเว็บไซต์
unit1/lesson-4.html     ครั้งที่ 4 กระบวนการพัฒนาเว็บไซต์ (WDLC 7 ขั้น)
unit1/lesson-5.html     ครั้งที่ 5 เครื่องมือ & เว็บเพจแรก + แบบทดสอบหลังเรียนหน่วย
assets/css/style.css    ธีม (สว่าง/มืด/อัตโนมัติ) และคอมโพเนนต์ทั้งหมด
assets/js/main.js       เครื่องเล่นแอนิเมชัน แบบทดสอบ ใบงาน ฯลฯ (ไม่ใช้ไลบรารีภายนอก)
docs/course-analysis.md เอกสารวิเคราะห์รายวิชา (ฉบับข้อความ)
```

แต่ละครั้งประกอบด้วย: จุดประสงค์ → เนื้อหา + แอนิเมชันทีละขั้น → ใบงาน (เช็กลิสต์ + เกณฑ์ให้คะแนน) → แบบทดสอบเฉลยทันที → สรุป

## วิธีเปิดใช้งาน

- เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย (เป็นเว็บแบบ Static ไม่ต้องมีเซิร์ฟเวอร์)
- หรือใช้ VS Code + ส่วนขยาย Live Server → คลิกขวา `index.html` → **Open with Live Server**

### เผยแพร่ด้วย GitHub Pages

1. ไปที่ **Settings → Pages** ของ repo นี้
2. Source: **Deploy from a branch** → Branch: `main` / โฟลเดอร์ `/ (root)` → Save
3. รอสักครู่ เว็บจะออนไลน์ที่ `https://<ชื่อผู้ใช้>.github.io/itrvc-web-development/`

## เพิ่ม/แก้แอนิเมชัน (สำหรับครู)

แอนิเมชันทุกตัวใช้เครื่องเล่นเดียวกันใน `main.js` เขียนด้วย HTML ล้วน:

```html
<figure class="anim" data-ms="4000">                 <!-- เวลาต่อขั้น (ms) -->
  <div class="stage">                                 <!-- พื้นที่ 16:9, ใช้พิกัด % -->
    <div class="actor c-blue" style="left:10%;top:50%" data-hl="1,3">…</div>
    <div class="bubble pop" style="left:50%;top:20%" data-only="2">โผล่เฉพาะขั้น 2</div>
    <div class="actor pop" style="left:80%;top:50%" data-in="3">โผล่ตั้งแต่ขั้น 3</div>
    <div class="flyer" style="--x1:10%;--y1:50%;--x2:80%;--y2:50%" data-only="4">แพ็กเก็ตวิ่ง</div>
  </div>
  <ol class="anim-steps"><li>คำอธิบายขั้นที่ 1</li> …</ol>   <!-- จำนวน li = จำนวนขั้น -->
</figure>
```

| แอตทริบิวต์ | ความหมาย |
|---|---|
| `data-in="3"` | แสดงตั้งแต่ขั้นที่ 3 เป็นต้นไป |
| `data-only="2,4-6"` | แสดงเฉพาะขั้นที่ระบุ |
| `data-hl="1,3"` | ไฮไลต์ (เรืองแสง) ในขั้นที่ระบุ |
| `.flyer` + `--x1 --y1 --x2 --y2` | ข้อมูลวิ่งจากจุด 1 ไปจุด 2 วนซ้ำ |

ปุ่มควบคุม (เล่น/หยุด, ก่อน/ถัดไป, ความเร็ว) สร้างให้อัตโนมัติ เล่นเองเมื่อเลื่อนมาถึง และคลิกคำอธิบายแต่ละขั้นเพื่อกระโดดไปยังขั้นนั้นได้

ความก้าวหน้า คะแนนแบบทดสอบ และเช็กลิสต์ใบงาน บันทึกไว้ในเบราว์เซอร์ของผู้เรียนแต่ละคน (localStorage) เท่านั้น
