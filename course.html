02

จุดประสงค์ & สมรรถนะรายวิชา

จำแนกเป็นความรู้ (K) ทักษะ (S) และเจตคติ/กิจนิสัย (A)

จุดประสงค์รายวิชา

  1. [K] รู้และเข้าใจเกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์
  2. [S] มีทักษะในการวิเคราะห์ความต้องการผู้ใช้งาน ออกแบบ สร้าง ทดสอบ อัปโหลด และเผยแพร่เว็บไซต์
  3. [A] มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความรับผิดชอบ การคิดเชิงนวัตกรรม มีความละเอียดรอบคอบและการทำงานเป็นทีม
  4. [S] มีความสามารถประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์ในงานอาชีพ

สมรรถนะรายวิชา

  1. ประมวลความรู้เกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ตามหลักการ
  2. สร้างเว็บไซต์ตามหลักการ
  3. ประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์สำหรับใช้งานในงานอาชีพ
03

แตกคำอธิบายรายวิชา → 5 หน่วยการเรียน

นำวลีในคำอธิบายรายวิชามาจัดกลุ่ม และเรียงตามวงจรการพัฒนาเว็บไซต์

“ศึกษาและปฏิบัติเกี่ยวกับหลักการสร้างเว็บไซต์ กระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ วิเคราะห์ความต้องการของผู้ใช้งาน การออกแบบส่วนติดต่อผู้ใช้ ลักษณะของส่วนติดต่อผู้ใช้ การจัดวางองค์ประกอบ การติดตั้งโปรแกรมจำลอง Web Server การสร้างเว็บไซต์ด้วยโปรแกรมภาษาหรือโปรแกรมสำเร็จรูป ออกแบบหน้าเว็บเพจให้เหมาะสมตามหลักการ วัตถุประสงค์การใช้งาน อัปโหลด (Upload) เผยแพร่ใช้ในงานอาชีพ”

วลีจากคำอธิบายรายวิชาหน่วยการเรียนสัปดาห์จุดประสงค์สมรรถนะ
หลักการสร้างเว็บไซต์ · กระบวนการพัฒนา · โครงสร้างการทำงานของเว็บไซต์1 หลักการและโครงสร้างการทำงานของเว็บไซต์1–31, 31
วิเคราะห์ความต้องการของผู้ใช้งาน · ออกแบบส่วนติดต่อผู้ใช้ · ลักษณะส่วนติดต่อผู้ใช้ · การจัดวางองค์ประกอบ2 การวิเคราะห์ความต้องการผู้ใช้และการออกแบบส่วนติดต่อผู้ใช้4–62, 31, 2
การติดตั้งโปรแกรมจำลอง Web Server · การสร้างเว็บไซต์ด้วยโปรแกรมภาษา (HTML)3 โปรแกรมจำลอง Web Server และการสร้างเว็บด้วย HTML7–92, 42
การสร้างเว็บไซต์ด้วยโปรแกรมภาษา (CSS, JavaScript) · ออกแบบหน้าเว็บเพจให้เหมาะสมตามหลักการ วัตถุประสงค์การใช้งาน4 การตกแต่งเว็บด้วย CSS, Responsive และ JavaScript10–122, 42, 3

04

หน่วยการเรียน หัวข้อย่อย และสมรรถนะประจำหน่วย

5 หน่วย · หน่วยละ 3 สัปดาห์ (15 ชั่วโมง)

หน่วยที่ 1 หลักการและโครงสร้างการทำงานของเว็บไซต์

สมรรถนะประจำหน่วย: แสดงความรู้เกี่ยวกับหลักการ โครงสร้างการทำงาน และกระบวนการพัฒนาเว็บไซต์ และใช้เครื่องมือตรวจสอบการทำงานของเว็บได้

  • 1.1 อินเทอร์เน็ต เวิลด์ไวด์เว็บ ประวัติ คำศัพท์ ประเภทเว็บไซต์ ส่วนประกอบของ URL · IP Address · Port
  • 1.2 DNS และ DNS Record · Client–Server · HTTP Request/Response · Status Code · HTTPS/TLS · การแสดงผลของเบราว์เซอร์
  • 1.3 HTML/CSS/JS · Frontend/Backend/Database · Static/Dynamic · โครงสร้างเว็บไซต์ 4 แบบ · วงจรการพัฒนาเว็บไซต์ 7 ขั้น · วางแผนโครงงาน
สื่อการเรียน หน่วยที่ 1

หน่วยที่ 2 การวิเคราะห์ความต้องการผู้ใช้และการออกแบบส่วนติดต่อผู้ใช้

สมรรถนะประจำหน่วย: วิเคราะห์ความต้องการของผู้ใช้งาน และออกแบบส่วนติดต่อผู้ใช้และการจัดวางองค์ประกอบหน้าเว็บเพจให้เหมาะสมกับวัตถุประสงค์

  • 2.1 เป้าหมาย SMART · กลุ่มผู้ใช้ · วิธีเก็บความต้องการ · Persona · User Journey · Requirements (MoSCoW)
  • 2.2 Information Architecture · Card sorting · Sitemap · หลัก UX (Nielsen, Jakob, Fitts, Hick, Miller)
  • 2.3 ลำดับสายตา Z/F · Grid · Spacing · C.R.A.P. · สีและคอนทราสต์ WCAG · ตัวอักษรไทย · Accessibility · Responsive · Wireframe → Mockup → Prototype (Figma)
