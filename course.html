วิเคราะห์รายวิชา การสร้างเว็บไซต์

แตกคำอธิบายรายวิชาเป็น 7 หน่วยการเรียน จัดลำดับตามวงจรการพัฒนาเว็บไซต์ (วางแผน → วิเคราะห์ → ออกแบบ → พัฒนา → ทดสอบ → เผยแพร่ → ดูแลรักษา) กำหนดสมรรถนะประจำหน่วย แผนการสอน 15 สัปดาห์ และการวัดผล พร้อมตารางเทียบกับการจัดสอนแบบเข้มข้น 5 วันบนเว็บนี้

02

จุดประสงค์ & สมรรถนะรายวิชา

จำแนกเป็นความรู้ (K) ทักษะ (S) และเจตคติ/กิจนิสัย (A)

จุดประสงค์รายวิชา

  1. [K] รู้และเข้าใจเกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์
  2. [S] มีทักษะในการวิเคราะห์ความต้องการผู้ใช้งาน ออกแบบ สร้าง ทดสอบ อัปโหลด และเผยแพร่เว็บไซต์
  3. [A] มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความรับผิดชอบ การคิดเชิงนวัตกรรม มีความละเอียดรอบคอบและการทำงานเป็นทีม
  4. [S] มีความสามารถประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์ในงานอาชีพ

สมรรถนะรายวิชา

  1. ประมวลความรู้เกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ตามหลักการ
  2. สร้างเว็บไซต์ตามหลักการ
  3. ประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์สำหรับใช้งานในงานอาชีพ
03

แตกคำอธิบายรายวิชา → หน่วยการเรียน

นำวลีในคำอธิบายรายวิชามาจัดกลุ่ม และเรียงตามวงจรการพัฒนาเว็บไซต์

“ศึกษาและปฏิบัติเกี่ยวกับหลักการสร้างเว็บไซต์ กระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ วิเคราะห์ความต้องการของผู้ใช้งาน การออกแบบส่วนติดต่อผู้ใช้ ลักษณะของส่วนติดต่อผู้ใช้ การจัดวางองค์ประกอบ การติดตั้งโปรแกรมจำลอง Web Server การสร้างเว็บไซต์ด้วยโปรแกรมภาษาหรือโปรแกรมสำเร็จรูป ออกแบบหน้าเว็บเพจให้เหมาะสมตามหลักการ วัตถุประสงค์การใช้งาน อัปโหลด (Upload) เผยแพร่ใช้ในงานอาชีพ”

วลีจากคำอธิบายรายวิชาหน่วยการเรียนสัปดาห์จุดประสงค์สมรรถนะ

หน่วยการเรียน หัวข้อย่อย และสมรรถนะประจำหน่วย

7 หน่วย · 15 สัปดาห์ · 75 ชั่วโมง

หน่วยที่ 1 หลักการและโครงสร้างการทำงานของเว็บไซต์ 3 สัปดาห์ · 15 ชม.

สมรรถนะประจำหน่วย: แสดงความรู้เกี่ยวกับหลักการ โครงสร้างการทำงาน และกระบวนการพัฒนาเว็บไซต์ และใช้เครื่องมือตรวจสอบการทำงานของเว็บได้

  • 1.1 อินเทอร์เน็ต เวิลด์ไวด์เว็บ ประวัติ คำศัพท์ ประเภทเว็บไซต์ ส่วนประกอบของ URL
  • 1.2 IP Address · Port · DNS และ DNS Record · Client–Server · HTTP Request/Response · Status Code · HTTPS/TLS
  • 1.3 การแสดงผลของเบราว์เซอร์ · HTML/CSS/JS · Frontend/Backend/Database · Static/Dynamic · โครงสร้างเว็บไซต์ 4 แบบ
  • 1.4 วงจรการพัฒนาเว็บไซต์ (WDLC) 7 ขั้น · บทบาททีมพัฒนา · วางแผนโครงงาน
