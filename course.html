02

จุดประสงค์ & สมรรถนะรายวิชา

สิ่งที่ผู้เรียนต้องรู้ ทำได้ และมีเจตคติที่ดี

จุดประสงค์รายวิชา

  1. รู้และเข้าใจเกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์
  2. มีทักษะในการวิเคราะห์ความต้องการผู้ใช้งาน ออกแบบ สร้าง ทดสอบ อัปโหลด และเผยแพร่เว็บไซต์
  3. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความรับผิดชอบ การคิดเชิงนวัตกรรม มีความละเอียดรอบคอบและการทำงานเป็นทีม
  4. มีความสามารถประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์ในงานอาชีพ

สมรรถนะรายวิชา

  1. ประมวลความรู้เกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ตามหลักการ
  2. สร้างเว็บไซต์ตามหลักการ
  3. ประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์สำหรับใช้งานในงานอาชีพ

อ่านให้เป็นจุดประสงค์ข้อ 1 = ความรู้ (K) · ข้อ 2, 4 = ทักษะ (S) · ข้อ 3 = เจตคติ/กิจนิสัย (A) ซึ่งต้องสอดแทรกในทุกหน่วย โดยเฉพาะการทำงานเป็นทีมในโครงงาน

03

แตกคำอธิบายรายวิชา → หน่วยการเรียน

นำวลีในคำอธิบายรายวิชามาจัดกลุ่ม แล้วเรียงตามลำดับกระบวนการพัฒนาเว็บไซต์

“ศึกษาและปฏิบัติเกี่ยวกับหลักการสร้างเว็บไซต์ กระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ วิเคราะห์ความต้องการของผู้ใช้งาน การออกแบบส่วนติดต่อผู้ใช้ ลักษณะของส่วนติดต่อผู้ใช้ การจัดวางองค์ประกอบ การติดตั้งโปรแกรมจำลอง Web Server การสร้างเว็บไซต์ด้วยโปรแกรมภาษาหรือโปรแกรมสำเร็จรูป ออกแบบหน้าเว็บเพจให้เหมาะสมตามหลักการ วัตถุประสงค์การใช้งาน อัปโหลด (Upload) เผยแพร่ใช้ในงานอาชีพ”

วลีจากคำอธิบายรายวิชาหน่วยการเรียนจุดประสงค์สมรรถนะ
หลักการสร้างเว็บไซต์ · กระบวนการพัฒนา · โครงสร้างการทำงานของเว็บไซต์หน่วยที่ 1 หลักการและโครงสร้างการทำงานของเว็บไซต์1, 31
วิเคราะห์ความต้องการของผู้ใช้งานหน่วยที่ 2 การวิเคราะห์ความต้องการผู้ใช้และการวางแผนเว็บไซต์2, 31, 2
การออกแบบส่วนติดต่อผู้ใช้ · ลักษณะของส่วนติดต่อผู้ใช้ · การจัดวางองค์ประกอบ · ออกแบบหน้าเว็บเพจให้เหมาะสมหน่วยที่ 3 การออกแบบส่วนติดต่อผู้ใช้และหน้าเว็บเพจ2, 32
การติดตั้งโปรแกรมจำลอง Web Serverหน่วยที่ 4 การติดตั้งโปรแกรมจำลอง Web Server22
การสร้างเว็บไซต์ด้วยโปรแกรมภาษาหน่วยที่ 5 การสร้างเว็บไซต์ด้วยภาษา HTML และ CSS2, 42, 3
การสร้างเว็บไซต์ด้วยโปรแกรมสำเร็จรูปหน่วยที่ 6 การสร้างเว็บไซต์ด้วยโปรแกรมสำเร็จรูป (CMS)2, 42, 3
อัปโหลด (Upload) เผยแพร่ใช้ในงานอาชีพ · ทดสอบหน่วยที่ 7 การทดสอบ อัปโหลด และเผยแพร่เว็บไซต์2, 3, 43
04

หน่วยการเรียนและหัวข้อย่อย

7 หน่วย + โครงงาน รวม 18 ครั้ง (90 ชั่วโมง)

หน่วยที่ 1 หลักการและโครงสร้างการทำงานของเว็บไซต์ 5 ครั้ง · 25 ชม.

  • 1.1 อินเทอร์เน็ต เวิลด์ไวด์เว็บ และคำศัพท์พื้นฐาน (เว็บเพจ เว็บไซต์ โฮมเพจ เบราว์เซอร์ URL โดเมน)
  • 1.2 การทำงานของเว็บ: Client–Server, IP, DNS, HTTP/HTTPS, Status Code
  • 1.3 โครงสร้างและองค์ประกอบของเว็บไซต์: HTML/CSS/JS, Frontend/Backend, Static/Dynamic, โครงสร้างเว็บไซต์ 4 แบบ, ส่วนประกอบหน้าเว็บ
  • 1.4 กระบวนการพัฒนาเว็บไซต์ (Web Development Life Cycle) 7 ขั้น และบทบาทของทีม
  • 1.5 เครื่องมือพัฒนาเว็บ (Editor, Browser, DevTools) และสร้างเว็บเพจแรกด้วย HTML
เข้าเรียนหน่วยที่ 1

หน่วยที่ 2 การวิเคราะห์ความต้องการผู้ใช้และการวางแผนเว็บไซต์ 2 ครั้ง · 10 ชม.

  • 2.1 การกำหนดวัตถุประสงค์ของเว็บไซต์และกลุ่มเป้าหมาย การสร้าง Persona
  • 2.2 วิธีเก็บความต้องการ: สัมภาษณ์ แบบสอบถาม สังเกต วิเคราะห์เว็บไซต์คู่แข่ง/ตัวอย่าง
  • 2.3 การจัดระเบียบเนื้อหา (Information Architecture) และการเขียนแผนผังเว็บไซต์ (Sitemap)
  • 2.4 การเขียนเอกสารความต้องการ (Requirements) และแผนการดำเนินงาน (Gantt Chart)

หน่วยที่ 3 การออกแบบส่วนติดต่อผู้ใช้และหน้าเว็บเพจ 2 ครั้ง · 10 ชม.

  • 3.1 หลัก UI/UX และลักษณะของส่วนติดต่อผู้ใช้ที่ดี (ใช้ง่าย สม่ำเสมอ ตอบสนอง เข้าถึงได้)
  • 3.2 การจัดวางองค์ประกอบ: Layout, Grid, ลำดับความสำคัญทางสายตา, ช่องว่าง (Whitespace)
  • 3.3 การเลือกใช้สี ตัวอักษร ภาพ และไอคอนให้เหมาะกับวัตถุประสงค์
  • 3.4 Responsive Design และการทำ Wireframe / Mockup (เช่น Figma)

หน่วยที่ 4 การติดตั้งโปรแกรมจำลอง Web Server 1 ครั้ง · 5 ชม.

  • 4.1 Web Server คืออะไร (Apache, Nginx) · localhost / 127.0.0.1 · พอร์ต
  • 4.2 ติดตั้งและตั้งค่า XAMPP (Apache · MySQL/MariaDB · PHP) โฟลเดอร์ htdocs · phpMyAdmin
  • 4.3 ติดตั้ง VS Code + ส่วนขยาย Live Server และทดสอบเว็บผ่าน localhost

หน่วยที่ 5 การสร้างเว็บไซต์ด้วยภาษา HTML และ CSS 3 ครั้ง · 15 ชม.

  • 5.1 HTML: หัวข้อ ย่อหน้า รายการ ลิงก์ รูปภาพ ตาราง ฟอร์ม และแท็กเชิงความหมาย (Semantic)
  • 5.2 CSS: Selector, สีและฟอนต์, Box Model, Flexbox และ Grid
  • 5.3 Responsive (Media Query), JavaScript เบื้องต้น และเชื่อมโยงหลายหน้าเป็นเว็บไซต์

หน่วยที่ 6 การสร้างเว็บไซต์ด้วยโปรแกรมสำเร็จรูป (CMS) 2 ครั้ง · 10 ชม.

  • 6.1 CMS คืออะไร เปรียบเทียบ WordPress, Joomla, Google Sites, Wix
  • 6.2 ติดตั้ง WordPress บน localhost (XAMPP) · ธีม · ปลั๊กอิน
  • 6.3 สร้างหน้า โพสต์ เมนู วิดเจ็ต และจัดการผู้ใช้

หน่วยที่ 7 การทดสอบ อัปโหลด และเผยแพร่เว็บไซต์ 2 ครั้ง · 10 ชม.

  • 7.1 การทดสอบเว็บไซต์: ลิงก์ ฟังก์ชัน การแสดงผลหลายอุปกรณ์ ความเร็ว การเข้าถึง
  • 7.2 โดเมนเนม Web Hosting และการเลือกผู้ให้บริการ
  • 7.3 อัปโหลดด้วย FTP (FileZilla) / GitHub Pages · SEO เบื้องต้น · การดูแลรักษาเว็บไซต์
