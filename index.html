5 หน่วย = วงจรพัฒนาเว็บไซต์จริง

ทุกหน่วยต่อยอดโครงงานเว็บไซต์ของตัวเองชิ้นเดียว จนหน่วยสุดท้ายเว็บออนไลน์บนโดเมนจริง

  1. หน่วยที่ 1 · เข้าใจระบบ + วางแผน

    เลือกหัวข้อเว็บและวางแผนโครงงาน — ผลลัพธ์: แผนโครงการ

  2. หน่วยที่ 2 · วิเคราะห์ + ออกแบบ

    Persona, Requirements, Sitemap, Wireframe, Mockup — ผลลัพธ์: ลิงก์ Figma

  3. หน่วยที่ 3 · พัฒนา (โครงสร้าง)

    เว็บทุกหน้าด้วย HTML บน XAMPP + ฟอร์ม PHP — ผลลัพธ์: เว็บบน localhost

  4. หน่วยที่ 4 · พัฒนา (หน้าตา + การโต้ตอบ)

    CSS ตาม Mockup, Responsive, เมนู JS — ผลลัพธ์: เว็บพร้อมเผยแพร่

  5. หน่วยที่ 5 · CMS + ทดสอบ + เผยแพร่ + ดูแลรักษา

    WordPress, ทดสอบ, DNS, SSH, Nginx, HTTPS — ผลลัพธ์: https://ซับโดเมนของคุณ 🎉
