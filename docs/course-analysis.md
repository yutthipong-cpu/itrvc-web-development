## จุดประสงค์รายวิชา

1. **[K]** รู้และเข้าใจเกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์
2. **[S]** มีทักษะในการวิเคราะห์ความต้องการผู้ใช้งาน ออกแบบ สร้าง ทดสอบ อัปโหลด และเผยแพร่เว็บไซต์
3. **[A]** มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความรับผิดชอบ การคิดเชิงนวัตกรรม มีความละเอียดรอบคอบและการทำงานเป็นทีม
4. **[S]** มีความสามารถประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์ในงานอาชีพ

## สมรรถนะรายวิชา

1. ประมวลความรู้เกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ตามหลักการ
2. สร้างเว็บไซต์ตามหลักการ
3. ประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์สำหรับใช้งานในงานอาชีพ

## หน่วยการเรียน หัวข้อ และสมรรถนะประจำหน่วย

**หน่วยที่ 1 หลักการและโครงสร้างการทำงานของเว็บไซต์ (สัปดาห์ 1–3)**
สมรรถนะ: แสดงความรู้เกี่ยวกับหลักการ โครงสร้างการทำงาน และกระบวนการพัฒนาเว็บไซต์ และใช้เครื่องมือตรวจสอบการทำงานของเว็บได้
- 1.1 อินเทอร์เน็ต WWW ประวัติ คำศัพท์ ประเภทเว็บไซต์ URL · IP · Port
- 1.2 DNS/DNS Record · Client–Server · HTTP · Status Code · HTTPS/TLS · การแสดงผลของเบราว์เซอร์
- 1.3 HTML/CSS/JS · Frontend/Backend/Database · Static/Dynamic · โครงสร้างเว็บไซต์ 4 แบบ · WDLC 7 ขั้น · วางแผนโครงงาน

**หน่วยที่ 2 การวิเคราะห์ความต้องการผู้ใช้และการออกแบบส่วนติดต่อผู้ใช้ (สัปดาห์ 4–6)**
สมรรถนะ: วิเคราะห์ความต้องการของผู้ใช้งาน และออกแบบส่วนติดต่อผู้ใช้และการจัดวางองค์ประกอบหน้าเว็บเพจให้เหมาะสมกับวัตถุประสงค์
- 2.1 SMART · กลุ่มผู้ใช้ · วิธีเก็บความต้องการ · Persona · User Journey · MoSCoW
- 2.2 Information Architecture · Card sorting · Sitemap · หลัก UX (Nielsen, Jakob, Fitts, Hick, Miller)
- 2.3 ลำดับสายตา Z/F · Grid · Spacing · C.R.A.P. · สี/คอนทราสต์ WCAG · ตัวอักษรไทย · Accessibility · Responsive · Wireframe → Mockup → Prototype

**หน่วยที่ 3 โปรแกรมจำลอง Web Server และการสร้างเว็บด้วย HTML (สัปดาห์ 7–9)**
สมรรถนะ: ติดตั้งโปรแกรมจำลอง Web Server และสร้างเว็บเพจด้วยภาษา HTML ตามหลักการ
- 3.1 Web Server · localhost · พอร์ต · XAMPP · phpMyAdmin · VS Code · Emmet · Live Server
- 3.2 HTML5 · Semantic · ข้อความ · ลิงก์และพาธ · รูปภาพ · ตาราง · สื่อ
- 3.3 ฟอร์ม GET/POST + PHP · XSS · Meta/SEO/Open Graph · ตรวจความถูกต้อง

**หน่วยที่ 4 การตกแต่งเว็บด้วย CSS, Responsive และ JavaScript (สัปดาห์ 10–12)**
สมรรถนะ: ตกแต่งและจัดวางหน้าเว็บด้วย CSS ให้รองรับทุกอุปกรณ์ และเพิ่มการโต้ตอบด้วย JavaScript
- 4.1 CSS 3 วิธี · Selector · Cascade/Specificity · Inheritance · สีและหน่วย · ฟอนต์ไทย
- 4.2 Box Model · display · position · Flexbox · Grid
- 4.3 Responsive · CSS Variables · Transition · Dark mode · JavaScript DOM/Event · DevTools

**หน่วยที่ 5 การสร้างเว็บด้วย CMS การทดสอบ และการเผยแพร่เว็บไซต์ (สัปดาห์ 13–15)**
สมรรถนะ: สร้างเว็บไซต์ด้วยโปรแกรมสำเร็จรูป ทดสอบ อัปโหลด และเผยแพร่บนเซิร์ฟเวอร์และโดเมนจริงอย่างปลอดภัย
- 5.1 CMS · WordPress: สถาปัตยกรรม ติดตั้ง Pages/Posts ธีม ปลั๊กอิน บทบาทผู้ใช้ ความปลอดภัย
- 5.2 การทดสอบ · โฮสติ้ง · โดเมน · DNS Record · Linux · SSH Key · สิทธิ์ไฟล์
- 5.3 SFTP/scp/rsync · Nginx server block · HTTPS (Let's Encrypt) · SEO · ดูแลรักษา · PDPA · นำเสนอ
