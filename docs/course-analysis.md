## จุดประสงค์รายวิชา

1. **[K]** รู้และเข้าใจเกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์
2. **[S]** มีทักษะในการวิเคราะห์ความต้องการผู้ใช้งาน ออกแบบ สร้าง ทดสอบ อัปโหลด และเผยแพร่เว็บไซต์
3. **[A]** มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความรับผิดชอบ การคิดเชิงนวัตกรรม มีความละเอียดรอบคอบและการทำงานเป็นทีม
4. **[S]** มีความสามารถประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์ในงานอาชีพ

## สมรรถนะรายวิชา

1. ประมวลความรู้เกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ตามหลักการ
2. สร้างเว็บไซต์ตามหลักการ
3. ประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์สำหรับใช้งานในงานอาชีพ

## หน่วยการเรียน หัวข้อ และสมรรถนะประจำหน่วย

**หน่วยที่ 1 หลักการและโครงสร้างการทำงานของเว็บไซต์ (3 สัปดาห์)**
สมรรถนะ: แสดงความรู้เกี่ยวกับหลักการ โครงสร้างการทำงาน และกระบวนการพัฒนาเว็บไซต์ และใช้เครื่องมือตรวจสอบการทำงานของเว็บได้
- 1.1 อินเทอร์เน็ต WWW ประวัติ คำศัพท์ ประเภทเว็บไซต์ ส่วนประกอบของ URL
- 1.2 IP · Port · DNS และ DNS Record · Client–Server · HTTP · Status Code · HTTPS/TLS
- 1.3 Rendering · HTML/CSS/JS · Frontend/Backend/Database · Static/Dynamic · โครงสร้างเว็บไซต์ 4 แบบ
- 1.4 วงจรการพัฒนาเว็บไซต์ 7 ขั้น · บทบาททีม · วางแผนโครงงาน

**หน่วยที่ 2 การวิเคราะห์ความต้องการผู้ใช้และการวางแผนเว็บไซต์ (2 สัปดาห์)**
สมรรถนะ: วิเคราะห์ความต้องการของผู้ใช้งานและจัดทำเอกสารวางแผนเว็บไซต์ตามหลักการ
- 2.1 เป้าหมาย SMART · กลุ่มผู้ใช้
- 2.2 สัมภาษณ์ แบบสอบถาม สังเกต วิเคราะห์คู่แข่ง
- 2.3 Persona · User Journey · Requirements · MoSCoW
- 2.4 Information Architecture · Card sorting · Sitemap

**หน่วยที่ 3 การออกแบบส่วนติดต่อผู้ใช้และหน้าเว็บเพจ (2 สัปดาห์)**
สมรรถนะ: ออกแบบส่วนติดต่อผู้ใช้และจัดวางองค์ประกอบหน้าเว็บเพจให้เหมาะสมกับวัตถุประสงค์และผู้ใช้
- 3.1 หลัก UX/UI · Nielsen's heuristics · Jakob/Fitts/Hick/Miller
- 3.2 ลำดับสายตา Z/F · Visual hierarchy · Grid · Spacing · C.R.A.P.
- 3.3 สี (60-30-10, คอนทราสต์ WCAG) · ตัวอักษรไทย · ภาพ ไอคอน ลิขสิทธิ์ · Accessibility
- 3.4 Responsive/Mobile-first · Wireframe → Mockup → Prototype (Figma)

**หน่วยที่ 4 การติดตั้งโปรแกรมจำลอง Web Server (1 สัปดาห์)**
สมรรถนะ: ติดตั้งและตั้งค่าโปรแกรมจำลอง Web Server และเครื่องมือพัฒนาเว็บได้ถูกต้อง
- 4.1 Web Server · localhost · พอร์ต · DocumentRoot
- 4.2 XAMPP · phpMyAdmin · แก้ปัญหาพอร์ตชน
- 4.3 VS Code · Emmet · Live Server

**หน่วยที่ 5 การสร้างเว็บไซต์ด้วยภาษา HTML, CSS และ JavaScript (3 สัปดาห์)**
สมรรถนะ: สร้างเว็บไซต์ด้วยโปรแกรมภาษาตามหลักการ รองรับการแสดงผลทุกอุปกรณ์
- 5.1 HTML5 Semantic · พาธ · รูป · ตาราง · สื่อ · ฟอร์ม GET/POST + PHP · Meta/SEO
- 5.2 CSS Selector · Specificity · หน่วย · ฟอนต์ · Box model · position · Flexbox · Grid
- 5.3 Responsive · CSS Variables · Transition · JavaScript DOM/Event

**หน่วยที่ 6 การสร้างเว็บไซต์ด้วยโปรแกรมสำเร็จรูป (2 สัปดาห์)**
สมรรถนะ: ติดตั้งและใช้งานโปรแกรมสำเร็จรูปสร้างเว็บไซต์สำหรับงานอาชีพ
- 6.1 CMS · สถาปัตยกรรม WordPress
- 6.2 ติดตั้ง WordPress บน XAMPP และบนเซิร์ฟเวอร์ (LEMP)
- 6.3 Pages/Posts · เมนู · ธีม · ปลั๊กอิน · บทบาทผู้ใช้ · ความปลอดภัย

**หน่วยที่ 7 การทดสอบ อัปโหลด และเผยแพร่เว็บไซต์ (2 สัปดาห์)**
สมรรถนะ: ทดสอบ อัปโหลด และเผยแพร่เว็บไซต์บนเซิร์ฟเวอร์และโดเมนจริงอย่างปลอดภัย
- 7.1 การทดสอบ · Lighthouse · Core Web Vitals
- 7.2 โฮสติ้ง · โดเมน · DNS · Linux · SSH Key · SFTP/scp/rsync · สิทธิ์ไฟล์
- 7.3 Nginx server block · HTTPS (Let's Encrypt) · SEO · ดูแลรักษา · PDPA · นำเสนอโครงงาน
