# วิเคราะห์รายวิชา 31900-0001 การสร้างเว็บไซต์

| รายการ | ข้อมูล |
|---|---|
| หน่วยกิต | 3 (ทฤษฎี 1 · ปฏิบัติ 4 · ศึกษาค้นคว้าด้วยตนเอง 0) |
| ปีหลักสูตร / ประเภท | 2567 / รายวิชาส่วนกลาง |
| เวลาเรียน | 18 สัปดาห์ × 5 ชม. = 90 ชม. (ท 18 + ป 72) |

## จุดประสงค์รายวิชา

1. รู้และเข้าใจเกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ — **K**
2. มีทักษะในการวิเคราะห์ความต้องการผู้ใช้งาน ออกแบบ สร้าง ทดสอบ อัปโหลด และเผยแพร่เว็บไซต์ — **S**
3. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความรับผิดชอบ การคิดเชิงนวัตกรรม มีความละเอียดรอบคอบและการทำงานเป็นทีม — **A**
4. มีความสามารถประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์ในงานอาชีพ — **S**

## สมรรถนะรายวิชา

1. ประมวลความรู้เกี่ยวกับกระบวนการพัฒนาและโครงสร้างการทำงานของเว็บไซต์ตามหลักการ
2. สร้างเว็บไซต์ตามหลักการ
3. ประยุกต์ใช้โปรแกรมภาษาหรือโปรแกรมสำเร็จรูปสร้างเว็บไซต์สำหรับใช้งานในงานอาชีพ

## หัวข้อย่อยแต่ละหน่วย

**หน่วยที่ 1 หลักการและโครงสร้างการทำงานของเว็บไซต์ (5 ครั้ง)**
- 1.1 อินเทอร์เน็ต เวิลด์ไวด์เว็บ คำศัพท์พื้นฐาน ประเภทเว็บไซต์ ส่วนประกอบของ URL
- 1.2 การทำงานของเว็บ: Client–Server, IP, DNS, HTTP Request/Response, Status Code, HTTPS
- 1.3 HTML/CSS/JS, Frontend/Backend/Database, Static/Dynamic, โครงสร้างเว็บไซต์ 4 แบบ, ส่วนประกอบหน้าเว็บ
- 1.4 กระบวนการพัฒนาเว็บไซต์ 7 ขั้น, Sitemap → Wireframe → Mockup → Website, ทีมพัฒนาเว็บ
- 1.5 เครื่องมือพัฒนาเว็บ, จากโค้ดสู่หน้าจอ (DOM/Render), โครงสร้าง HTML5, เว็บเพจแรก

**หน่วยที่ 2 การวิเคราะห์ความต้องการผู้ใช้และการวางแผนเว็บไซต์ (2 ครั้ง)**
- วัตถุประสงค์และกลุ่มเป้าหมาย, Persona
- การเก็บความต้องการ: สัมภาษณ์ แบบสอบถาม สังเกต วิเคราะห์เว็บคู่แข่ง
- Information Architecture และ Sitemap
- เอกสารความต้องการ (Requirements) และ Gantt Chart

**หน่วยที่ 3 การออกแบบส่วนติดต่อผู้ใช้และหน้าเว็บเพจ (2 ครั้ง)**
- หลัก UI/UX ลักษณะส่วนติดต่อผู้ใช้ที่ดี
- การจัดวางองค์ประกอบ: Layout, Grid, ลำดับสายตา, Whitespace
- สี ตัวอักษร ภาพ ไอคอน
- Responsive Design, Wireframe/Mockup ด้วย Figma

**หน่วยที่ 4 การติดตั้งโปรแกรมจำลอง Web Server (1 ครั้ง)**
- Web Server (Apache/Nginx), localhost, พอร์ต
- XAMPP (Apache, MySQL/MariaDB, PHP), htdocs, phpMyAdmin
- VS Code + Live Server

**หน่วยที่ 5 การสร้างเว็บไซต์ด้วยภาษา HTML และ CSS (3 ครั้ง)**
- HTML: ข้อความ รายการ ลิงก์ รูป ตาราง ฟอร์ม Semantic tags
- CSS: Selector สี ฟอนต์ Box Model Flexbox Grid
- Responsive (Media Query), JavaScript เบื้องต้น, เว็บไซต์หลายหน้า

**หน่วยที่ 6 การสร้างเว็บไซต์ด้วยโปรแกรมสำเร็จรูป (2 ครั้ง)**
- CMS: WordPress, Joomla, Google Sites, Wix
- ติดตั้ง WordPress บน localhost, ธีม, ปลั๊กอิน
- หน้า โพสต์ เมนู วิดเจ็ต ผู้ใช้

**หน่วยที่ 7 การทดสอบ อัปโหลด และเผยแพร่เว็บไซต์ (2 ครั้ง)**
- การทดสอบ: ลิงก์ ฟังก์ชัน หลายอุปกรณ์ ความเร็ว การเข้าถึง
- โดเมนเนม Web Hosting
- อัปโหลด FTP (FileZilla) / GitHub Pages, SEO เบื้องต้น, การดูแลรักษา
