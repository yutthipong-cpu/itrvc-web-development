Web Server คืออะไร

โปรแกรมที่ “รอฟัง” คำขอที่พอร์ต 80/443 แล้วส่งไฟล์หรือผลลัพธ์ของโปรแกรมกลับไป

ซอฟต์แวร์จุดเด่นเจอที่ไหน
Nginx (เอ็นจิน-เอ็กซ์)เร็ว ใช้หน่วยความจำน้อย รับคนพร้อมกันได้มาก ทำ Reverse proxyเซิร์ฟเวอร์จริงส่วนใหญ่ · Day 5
Apache HTTP Serverเก่าแก่ ยืดหยุ่น ตั้งค่ารายโฟลเดอร์ได้ด้วย .htaccessXAMPP · Shared hosting
LiteSpeedเข้ากันกับ Apache เร็ว มี Cache สำหรับ WordPressโฮสติ้งเชิงพาณิชย์
IISของ Microsoft ทำงานกับ ASP.NETองค์กรที่ใช้ Windows Server
Live Server / Node.jsเซิร์ฟเวอร์เล็ก ๆ สำหรับพัฒนา รีเฟรชอัตโนมัติVS Code บนเครื่องเรา

โปรแกรมจำลอง (Local)

  • อยู่ในเครื่องเรา http://localhost
  • คนอื่นเข้าไม่ได้ (ปลอดภัย ทดลองได้เต็มที่)
  • ไม่ต้องมีโดเมน/เน็ต
  • XAMPP, Laragon, MAMP, Docker
→

เซิร์ฟเวอร์จริง (Production)

  • อยู่บนอินเทอร์เน็ต มี Public IP
  • เข้าผ่านโดเมนของเรา + HTTPS
  • เปิด 24 ชม. ต้องดูแลความปลอดภัย
  • Linux + Nginx/Apache (Day 5)

ชื่อ Apache มักถูกเล่าว่ามาจาก “a patchy server” เพราะยุคแรกสร้างจากการเอา แพตช์ (patch) หลายชิ้นมาปะรวมกัน (ผู้สร้างบอกว่าตั้งตามชื่อชนเผ่าอเมริกันพื้นเมือง แต่มุกนี้ติดปากวงการไปแล้ว)

02

localhost ทำงานอย่างไร (XAMPP)

เหมือนอินเทอร์เน็ตจำลองในเครื่องเดียว — เข้าใจตรงนี้แล้ว Day 5 จะง่ายมาก

เปิดไฟล์ .php ด้วยการ ดับเบิลคลิก (ที่อยู่เป็น file:///C:/…) จะเห็นโค้ด PHP ดิบ ๆ หรือหน้าว่าง เพราะไม่ได้ผ่าน Apache + PHP — ต้องเปิดผ่าน http://localhost/… เสมอ

03

ติดตั้ง XAMPP & แก้ปัญหาที่เจอบ่อย

XAMPP = X (ทุก OS) + Apache + MariaDB + PHP + Perl

  1. ดาวน์โหลดจาก apachefriends.org ติดตั้งที่ C:\xampp (อย่าติดตั้งใน Program Files เพราะติดสิทธิ์ของ Windows)
  2. เปิด XAMPP Control Panel (คลิกขวา Run as administrator) → กด Start ที่ Apache และ MySQL → ช่องเป็นสีเขียว
  3. เปิด http://localhost เห็นหน้า Welcome = Apache ทำงาน · เปิด http://localhost/phpmyadmin = จัดการฐานข้อมูล
  4. สร้างโฟลเดอร์ C:\xampp\htdocs\myweb → ใส่ index.html → เปิด http://localhost/myweb/
  5. ทดสอบ PHP: สร้าง info.php ใส่โค้ดด้านล่าง เปิด http://localhost/myweb/info.php
htdocs/myweb/info.php
<?php
echo "<h1>สวัสดีจาก PHP เวอร์ชัน " . phpversion() . "</h1>";
echo "เวลาบนเซิร์ฟเวอร์: " . date('d/m/Y H:i:s');
// phpinfo();   ← เปิดบรรทัดนี้เพื่อดูการตั้งค่า PHP ทั้งหมด (ห้ามทิ้งไว้บนเซิร์ฟเวอร์จริง!)
อาการสาเหตุวิธีแก้
Apache Start ไม่ได้ / “Port 80 in use”โปรแกรมอื่นใช้พอร์ต 80 (IIS, Skype, VMware)ปิดโปรแกรมนั้น หรือ Config → httpd.conf แก้ Listen 80 เป็น Listen 8080 แล้วเข้า localhost:8080
MySQL Start ไม่ได้พอร์ต 3306 ชน (มี MySQL อื่นติดตั้งอยู่)ปิด Service MySQL ตัวอื่นใน services.msc หรือเปลี่ยนพอร์ต
เปิด localhost แล้วเจอ 404พิมพ์ชื่อโฟลเดอร์/ไฟล์ผิด หรือไม่ได้วางใน htdocsตรวจตำแหน่งไฟล์และตัวสะกด
ภาษาไทยเพี้ยนไฟล์ไม่ได้บันทึกเป็น UTF-8 / ขาด meta charsetVS Code มุมขวาล่างเลือก UTF-8 · ใส่ <meta charset="UTF-8">

ดูว่าใครใช้พอร์ต 80 อยู่: เปิด cmd พิมพ์ netstat -ano | findstr :80 แล้วนำเลข PID ไปดูใน Task Manager แท็บ Details

MySQL ใน XAMPP ใช้ผู้ใช้ root ไม่มีรหัสผ่าน — ใช้ได้เพราะอยู่ในเครื่องตัวเองเท่านั้น ห้าม ใช้ค่าแบบนี้บนเซิร์ฟเวอร์จริงเด็ดขาด

ทางเลือกที่เบากว่า: Laragon (Windows) สร้างโดเมนจำลองให้อัตโนมัติ เช่น myweb.test · หรือ Docker: docker run -d -p 8080:80 -v "%cd%":/usr/share/nginx/html nginx ได้ Nginx ใน 1 บรรทัด

  • Live Server — เปิดเว็บผ่าน 127.0.0.1:5500 รีเฟรชเองเมื่อบันทึก

ตั้งค่าที่ควรเปิด (Ctrl+,)

  • Word Wrap: on — ข้อความยาวไม่ล้นจอ

แท็กข้อความ & Semantic HTML

เลือกแท็กตาม “ความหมาย” ไม่ใช่ตามหน้าตา (หน้าตาเป็นหน้าที่ของ CSS)

แท็กความหมายหมายเหตุ
<h1>–<h6>หัวข้อ 6 ระดับh1 หน้าละ 1 อัน · ห้ามข้ามระดับ (h2 → h4)
<p>ย่อหน้าอย่าใช้ <br> หลายอันแทนการขึ้นย่อหน้า
<strong> / <b>สำคัญ / ตัวหนาstrong มีความหมาย “สำคัญ” (โปรแกรมอ่านหน้าจอเน้นเสียง)
<em> / <i>เน้นน้ำเสียง / ตัวเอียงภาษาไทยตัวเอียงอ่านยาก ใช้เท่าที่จำเป็น
<br> · <hr>ขึ้นบรรทัดใหม่ · เส้นแบ่งหัวข้อVoid element
<blockquote> · <code> · <mark>คำพูดอ้างอิง · โค้ด · ไฮไลต์
<!-- -->คอมเมนต์ไม่แสดงผล แต่ ดูได้ด้วย View source อย่าเขียนรหัสผ่านไว้!
โครงหน้าแบบ Semantic
<body>
  <header>   <!-- ส่วนหัว: โลโก้ -->
    <nav>…</nav>  <!-- เมนูหลัก -->
  </header>
  <main>     <!-- เนื้อหาหลัก (หน้าละ 1) -->
    <section>   <!-- หมวด มีหัวข้อ -->
      <h2>ผลงาน</h2>
      <article>…</article> <!-- ชิ้นงานอิสระ -->
    </section>
    <aside>ข่าวล่าสุด</aside>
  </main>
  <footer>© 2026</footer>
</body>

ทำไมไม่ใช้ <div> ทั้งหมด? หน้าตาเหมือนกัน แต่ Semantic tag บอก “ความหมาย” ให้ Google (เข้าใจว่าส่วนไหนเนื้อหาหลัก) และ โปรแกรมอ่านหน้าจอ ของผู้พิการทางสายตา (กระโดดไปที่ nav/main ได้ทันที)

รูปภาพบนเว็บ

แท็กเดียว แต่ทำให้เว็บช้าหรือเร็วได้มากที่สุด

รูปภาพแบบมืออาชีพ
<figure>
  <img src="images/team.webp"
       alt="นักเรียนสาขา IT 5 คนกำลังประกอบคอมพิวเตอร์"
       width="800" height="533"
       loading="lazy">
  <figcaption>กิจกรรมประกอบคอมพิวเตอร์ ปี 2569</figcaption>
</figure>
ชนิดไฟล์เหมาะกับหมายเหตุ
JPGภาพถ่ายบีบอัดแบบเสียคุณภาพ ไม่มีพื้นใส
PNGโลโก้ ภาพหน้าจอ ต้องการพื้นใสไฟล์ใหญ่ถ้าเป็นภาพถ่าย
WebPแทนได้ทั้ง JPG/PNGมักเล็กกว่า JPG ราว 25–35% รองรับทุกเบราว์เซอร์ปัจจุบัน
AVIFภาพถ่ายคุณภาพสูงเล็กกว่า WebP อีก แต่เข้ารหัสช้ากว่า
SVGโลโก้ ไอคอน กราฟิกเส้นเป็นโค้ด (เวกเตอร์) ขยายเท่าไรก็คม ไฟล์เล็กมาก
GIFภาพเคลื่อนไหวสั้น ๆไฟล์ใหญ่ · ใช้วิดีโอ MP4/WebM แทนจะเล็กกว่ามาก

ใส่ width/height เสมอ — เบราว์เซอร์จะจองพื้นที่ไว้ก่อนรูปโหลดเสร็จ เนื้อหาไม่ “กระโดด” (ลดค่า CLS — Cumulative Layout Shift ซึ่งเป็นคะแนนหนึ่งที่ Google ใช้วัดเว็บ)

loading="lazy" = โหลดรูปเมื่อเลื่อนใกล้ถึงเท่านั้น ประหยัดเน็ตผู้ใช้ · แต่ รูปแรกบนสุดของหน้า (Hero) ห้ามใส่ lazy เพราะจะทำให้เห็นช้าลง

alt ที่ดี อธิบายว่ารูป “สื่ออะไร” ไม่ใช่ “รูปภาพ1.jpg” · ถ้าเป็นรูปตกแต่งล้วน ๆ ใส่ alt="" (ว่าง) เพื่อให้โปรแกรมอ่านหน้าจอข้าม

Favicon (ไอคอนบนแท็บ): <link rel="icon" href="favicon.png"> ขนาด 32×32 หรือใช้ SVG · สร้างได้จากเว็บ favicon generator

รายการ & ตาราง

ตารางใช้กับ “ข้อมูล” เท่านั้น — ห้ามใช้จัดหน้าเว็บ (ยุค 2000 ทำกันแบบนั้น)

ตารางค่าเทอม
<table>
  <caption>ค่าใช้จ่ายต่อภาคเรียน</caption>
  <thead>
    <tr><th>ระดับ</th><th>ค่าเทอม</th></tr>
  </thead>
  <tbody>
    <tr><td>ปวช.</td><td>2,500</td></tr>
    <tr><td>ปวส.</td><td>3,500</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="2">*ไม่รวมค่าชุด</td></tr>
  </tfoot>
</table>
  • <tr> แถว · <th> หัวตาราง · <td> ช่องข้อมูล
  • colspan="2" รวมคอลัมน์ · rowspan="2" รวมแถว
  • <caption> ชื่อตาราง (ช่วย Accessibility)
  • รายการ: <ul> ไม่มีลำดับ · <ol> มีลำดับ (type="A", start="5") · <dl><dt><dd> คำศัพท์–คำอธิบาย
  • เมนูนำทางเขียนเป็น <nav><ul><li><a> — แล้วใช้ CSS จัดเป็นแนวนอน (Day 4)

ตารางกว้างบนมือถือจะล้นจอ — ครอบด้วย <div style="overflow-x:auto"> ให้เลื่อนแนวนอนได้ (เว็บนี้ก็ใช้วิธีนี้)

สื่อแบบต่าง ๆ
<!-- วิดีโอของเราเอง -->
<video src="media/intro.mp4" controls muted playsinline poster="images/cover.webp"></video>

<!-- Google Maps: แชร์ → ฝังแผนที่ -->
<iframe src="https://www.google.com/maps/embed?pb=..." loading="lazy"></iframe>

เบราว์เซอร์ ไม่อนุญาตให้วิดีโอเล่นอัตโนมัติพร้อมเสียง (เพราะผู้ใช้ไม่ชอบ) ถ้าอยากให้ autoplay ต้องใส่ muted ด้วยเสมอ

ฟอร์ม: ส่งข้อมูลไปเซิร์ฟเวอร์ (GET vs POST)

ทดลองจริงบน XAMPP — เห็นข้อมูลวิ่งจากฟอร์มไปถึง PHP

htdocs/myweb/contact.html
<form action="contact.php" method="post">
  <label for="name">ชื่อ</label>
  <input id="name" name="name" required>

  <label for="email">อีเมล</label>
  <input type="email" id="email" name="email" required>

  <label for="topic">เรื่อง</label>
  <select id="topic" name="topic">
    <option>สอบถามหลักสูตร</option>
    <option>อื่น ๆ</option>
  </select>

  <textarea name="msg" rows="4"></textarea>
  <button type="submit">ส่งข้อความ</button>
</form>
htdocs/myweb/contact.php
<?php
// รับค่า + ป้องกันโค้ดแปลกปลอม (XSS)
$name  = htmlspecialchars($_POST['name'] ?? '');
$email = htmlspecialchars($_POST['email'] ?? '');
$topic = htmlspecialchars($_POST['topic'] ?? '');
?>
<h1>ขอบคุณคุณ <?= $name ?></h1>
<p>เรื่อง “<?= $topic ?>”
   เราจะตอบกลับที่ <?= $email ?></p>
input typeบนมือถือได้อะไร
emailคีย์บอร์ดมี @ · ตรวจรูปแบบให้
telแป้นตัวเลขโทรศัพท์
numberแป้นตัวเลข · กำหนด min/max
dateปฏิทินเลือกวัน
passwordซ่อนตัวอักษร
radio / checkbox / fileเลือก 1 / หลายข้อ / แนบไฟล์

<label for="email"> ที่ตรงกับ id="email" ทำให้ คลิกที่ข้อความแล้วเคอร์เซอร์ไปที่ช่อง (กดง่ายขึ้นบนมือถือ) และโปรแกรมอ่านหน้าจออ่านชื่อช่องได้

required / type="email" เป็นการตรวจฝั่งเบราว์เซอร์ ซึ่ง ปิดได้ง่ายมาก (DevTools) — เซิร์ฟเวอร์ต้องตรวจซ้ำเสมอ กฎเหล็ก: “อย่าไว้ใจข้อมูลจากผู้ใช้”

XSS (Cross-Site Scripting): ถ้ามีคนพิมพ์ <script>…</script> ในช่องชื่อ แล้วเราแสดงผลตรง ๆ โค้ดนั้นจะรันในเบราว์เซอร์ของคนอื่น — htmlspecialchars() แปลง < เป็น &lt; จึงแสดงเป็นข้อความธรรมดา

Meta Tag · SEO · Open Graph · ตรวจความถูกต้อง

สิ่งที่อยู่ใน <head> ซึ่งผู้ใช้ไม่เห็น แต่ Google และโซเชียลเห็น

<head> ที่สมบูรณ์
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>ร้านกาแฟบ้านเรา | กาแฟคั่วสดจากดอยในจังหวัด</title>
  <meta name="description" content="กาแฟคั่วสดทุกวัน เปิด 7:00–17:00 สั่งออนไลน์ได้">
  <!-- Open Graph: หน้าตาตอนแชร์ใน Facebook / LINE -->
  <meta property="og:title" content="ร้านกาแฟบ้านเรา">
  <meta property="og:description" content="กาแฟคั่วสดจากดอย">
  <meta property="og:image" content="https://coffee.example.ac.th/images/share.jpg">
  <link rel="icon" href="images/favicon.png">
  <link rel="stylesheet" href="css/style.css">
</head>

title ควรยาวราว 50–60 ตัวอักษร · description ราว 150–160 ตัวอักษร (เกินจะถูกตัดในผลค้นหา) · ทุกหน้าต้อง ไม่ซ้ำกัน

og:image ต้องเป็น URL เต็ม (Absolute) และควรขนาด 1200×630px — ทดสอบหน้าตาการแชร์ได้ที่ Facebook Sharing Debugger หลังเว็บขึ้นโดเมนจริง (Day 5)

ตรวจ HTML ที่ validator.w3.org (เลือก Validate by Direct Input แล้ววางโค้ด) — จะบอกแท็กที่ลืมปิด ซ้อนผิด หรือแอตทริบิวต์ผิด พร้อมเลขบรรทัด

แบบทดสอบ Day 3

10 ข้อ

ไฟล์เว็บใน XAMPP ต้องวางไว้ที่โฟลเดอร์ใดจึงเปิดผ่าน http://localhost ได้

htdocs คือ DocumentRoot ของ Apache ใน XAMPP

Apache ใน XAMPP Start ไม่ได้เพราะพอร์ต 80 ถูกใช้ วิธีแก้ที่ถูกต้องคือ

หรือปิดโปรแกรมที่ใช้พอร์ต 80 อยู่

ไฟล์ about/team.html ต้องแสดงรูป images/logo.png (images อยู่ระดับเดียวกับโฟลเดอร์ about) ควรเขียน src อย่างไร

.. ถอยออกจาก about หนึ่งชั้น แล้วเข้า images

บรรทัดใดทำให้หน้าเว็บแสดงผลพอดีจอมือถือ

ถ้าไม่มี viewport มือถือจะแสดงแบบย่อหน้าเว็บขนาดคอมพิวเตอร์

โลโก้ที่ต้องคมชัดทุกขนาดจอและไฟล์เล็ก ควรใช้ไฟล์ชนิดใด

SVG เป็นเวกเตอร์ ขยายแล้วไม่แตก

ฟอร์มล็อกอินควรใช้ method ใด

POST ไม่แสดงรหัสผ่านใน URL (และต้องใช้ HTTPS)

PHP อ่านค่าจากช่อง <input name="email"> ที่ส่งแบบ POST อย่างไร

ชื่อใน [] ต้องตรงกับแอตทริบิวต์ name

แท็กใดเหมาะเป็นส่วน “เนื้อหาหลัก” ของหน้า (มีหน้าละ 1)

main ครอบเนื้อหาหลักที่ไม่ซ้ำกับหน้าอื่น

ทำไมควรใส่ width และ height ให้ <img>

ลด Layout Shift (CLS)

ฟังก์ชัน htmlspecialchars() ใน PHP ช่วยป้องกันอะไร

แปลง < > เป็นข้อความธรรมดา ไม่ให้รันเป็นโค้ด
