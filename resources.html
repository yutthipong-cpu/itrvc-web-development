คลังความรู้เสริม

รวมทุกอย่างที่ต้องเปิดดูบ่อยระหว่างเรียนและทำโครงงาน: ความหมายของคำศัพท์ วิธีแก้เมื่อเว็บมีปัญหา สรุปคำสั่ง คีย์ลัด และแหล่งเรียนรู้ต่อยอด — แต่ละรายการบอกไว้ว่าเรียนละเอียดในหน่วยไหน

คลังความรู้
อภิธานศัพท์ แก้ปัญหาที่พบบ่อย สรุป HTML สรุป CSS สรุป Linux · SSH · Nginx สรุป Git คีย์ลัด เช็กลิสต์ก่อนส่งงาน แหล่งเรียนรู้เพิ่มเติม

อภิธานศัพท์

พิมพ์คำที่อยากรู้ (ไทยหรืออังกฤษ) เพื่อกรองรายการ · ตัวเลขในวงเล็บ = หน่วยที่เรียน

A recordDNS record ที่ชี้ชื่อโดเมนไปยัง IPv4 (หน่วย 1, 5)
AAAA recordDNS record ที่ชี้ชื่อโดเมนไปยัง IPv6 (หน่วย 1)
Accessibility (a11y)การออกแบบให้ทุกคนใช้ได้ รวมผู้พิการ ตามหลัก WCAG — POUR (หน่วย 2)
alt textข้อความอธิบายรูปในแท็ก <img> สำหรับโปรแกรมอ่านหน้าจอและเมื่อรูปโหลดไม่ขึ้น (หน่วย 3)
Apacheโปรแกรมเว็บเซิร์ฟเวอร์ยอดนิยม อยู่ใน XAMPP ตั้งค่ารายโฟลเดอร์ด้วย .htaccess ได้ (หน่วย 3)
Attribute (แอตทริบิวต์)คุณสมบัติเพิ่มเติมในแท็กเปิด เช่น href, src, alt (หน่วย 3)
Backend (หลังบ้าน)ส่วนประมวลผลฝั่งเซิร์ฟเวอร์ที่ผู้ใช้มองไม่เห็น เช่น PHP, Node.js (หน่วย 1)
Bandwidth (แบนด์วิดท์)ปริมาณข้อมูลที่ส่งผ่านได้ต่อหน่วยเวลา / ปริมาณรับส่งที่โฮสติ้งอนุญาต (หน่วย 5)
Box Modelทุกองค์ประกอบคือกล่อง: content → padding → border → margin (หน่วย 4)
Breakpointความกว้างจอที่ Layout เปลี่ยนรูปแบบ เช่น 768px, 992px (หน่วย 2, 4)
Browser (เบราว์เซอร์)โปรแกรมขอและแสดงผลเว็บ เช่น Chrome, Edge, Firefox, Safari (หน่วย 1)
Cache (แคช)การเก็บสำเนาข้อมูลไว้ใช้ซ้ำให้เร็วขึ้น มีทั้งในเบราว์เซอร์ DNS และเซิร์ฟเวอร์ (หน่วย 1, 5)
CDNContent Delivery Network — เครือข่ายเซิร์ฟเวอร์ทั่วโลกที่เก็บสำเนาไฟล์เว็บไว้ใกล้ผู้ใช้ (หน่วย 1)
Certificate (ใบรับรอง SSL/TLS)เอกสารดิจิทัลยืนยันตัวตนของเว็บไซต์ ออกโดย CA ใช้ในการเชื่อมต่อ HTTPS (หน่วย 1, 5)
certbotโปรแกรมขอและต่ออายุใบรับรองจาก Let's Encrypt อัตโนมัติ (หน่วย 5)
Client (ไคลเอนต์)ฝ่ายผู้ขอบริการ เช่น เบราว์เซอร์บนเครื่องผู้ใช้ (หน่วย 1)
CLSCumulative Layout Shift — ค่าวัดการ “กระโดด” ของเนื้อหาระหว่างโหลด ควร ≤ 0.1 (หน่วย 3, 5)
CMSContent Management System — ระบบจัดการเนื้อหาผ่านหน้าแอดมิน เช่น WordPress (หน่วย 5)
CNAME recordDNS record ที่ทำให้ชื่อหนึ่งเป็น “ชื่อเล่น” ของอีกชื่อ เช่น www → โดเมนหลัก (หน่วย 1, 5)
Container queryCSS ที่ปรับรูปแบบตามขนาดกล่องแม่แทนขนาดจอ (@container) (หน่วย 4)
Cookie (คุกกี้)ข้อมูลเล็ก ๆ ที่เซิร์ฟเวอร์ฝากไว้ในเบราว์เซอร์ ใช้จำการล็อกอิน/การตั้งค่า (หน่วย 1)
CSSCascading Style Sheets — ภาษากำหนดหน้าตาและการจัดวาง (หน่วย 1, 4)
CSSOMโครงสร้างต้นไม้ของกฎ CSS ที่เบราว์เซอร์สร้างระหว่างการแสดงผล (หน่วย 1)
CTA (Call to Action)ปุ่มหรือข้อความที่ชวนให้ผู้ใช้ทำสิ่งสำคัญ เช่น “สมัครเรียน” (หน่วย 2)
Database (ฐานข้อมูล)ที่เก็บข้อมูลอย่างเป็นระบบ เช่น MySQL/MariaDB (หน่วย 1, 5)
DevToolsเครื่องมือนักพัฒนาในเบราว์เซอร์ (กด F12) ดูโค้ด Network Console ฯลฯ (ทุกหน่วย)
DNSDomain Name System — ระบบแปลงชื่อโดเมนเป็น IP Address (หน่วย 1, 5)
DocumentRootโฟลเดอร์ที่เว็บเซิร์ฟเวอร์ใช้เป็นราก (/) ของเว็บ เช่น htdocs, /var/www/… (หน่วย 3, 5)
DOMDocument Object Model — โครงสร้างต้นไม้ของหน้าเว็บที่ JavaScript อ่าน/แก้ไขได้ (หน่วย 1, 4)
Domain name (โดเมนเนม)ชื่อเว็บที่จดทะเบียน ไม่ซ้ำกันทั้งโลก ต้องต่ออายุ (หน่วย 1, 5)
Element (อิลิเมนต์)แท็กเปิด + เนื้อหา + แท็กปิด รวมเป็นหนึ่งชิ้นของหน้าเว็บ (หน่วย 3)
Emmetตัวย่อสร้างโค้ดเร็วใน VS Code เช่น ! หรือ ul>li*5 แล้วกด Tab (หน่วย 3)
Event (เหตุการณ์)สิ่งที่เกิดขึ้นบนหน้าเว็บ เช่น click, input, submit ที่ JavaScript รอฟังได้ (หน่วย 4)
Faviconไอคอนเล็กบนแท็บเบราว์เซอร์ (หน่วย 3)
Firewall (ไฟร์วอลล์)ระบบกั้นการเชื่อมต่อที่ไม่อนุญาต เช่น ufw บน Linux (หน่วย 5)
Flexboxระบบจัดวาง CSS แบบ 1 มิติ (แถวหรือคอลัมน์) (หน่วย 4)
Fragment (#)ส่วนท้าย URL ที่ใช้กระโดดไปยัง id ในหน้า ไม่ถูกส่งไปเซิร์ฟเวอร์ (หน่วย 1)
Frontend (หน้าบ้าน)ส่วนที่ผู้ใช้เห็นและโต้ตอบในเบราว์เซอร์: HTML, CSS, JS (หน่วย 1)
FTP / SFTPโปรโตคอลส่งไฟล์ · FTP (พอร์ต 21) ไม่เข้ารหัส · SFTP (พอร์ต 22 ผ่าน SSH) เข้ารหัส (หน่วย 5)
GET / POSTHTTP Method · GET ส่งข้อมูลใน URL · POST ส่งข้อมูลใน Body (หน่วย 1, 3)
Gitระบบควบคุมเวอร์ชันของโค้ด บันทึกประวัติทุกการแก้ไข (หน่วย 5)
Grid (CSS Grid)ระบบจัดวาง CSS แบบ 2 มิติ (แถวและคอลัมน์) (หน่วย 4)
Header (HTTP)ข้อมูลประกอบในคำขอ/คำตอบ HTTP เช่น Host, Content-Type (หน่วย 1)
Hosting (โฮสติ้ง)พื้นที่บนเซิร์ฟเวอร์สำหรับวางเว็บ: Shared, VPS, Cloud, Dedicated (หน่วย 5)
HSTSHeader ที่สั่งให้เบราว์เซอร์ใช้ HTTPS กับเว็บนี้เสมอ (หน่วย 1)
HTMLHyperText Markup Language — ภาษากำหนดโครงสร้างเนื้อหาเว็บเพจ (หน่วย 1, 3)
HTTP / HTTPSโปรโตคอลรับส่งเว็บ · HTTPS = HTTP + การเข้ารหัส TLS (หน่วย 1)
Hyperlink (ไฮเปอร์ลิงก์)ข้อความ/รูปที่คลิกแล้วไปยังที่อื่น สร้างด้วย <a href> (หน่วย 1, 3)
INPInteraction to Next Paint — ค่าวัดความไวในการตอบสนองเมื่อผู้ใช้กด ควร ≤ 200 ms (หน่วย 5)
IP Addressหมายเลขประจำอุปกรณ์บนเครือข่าย IPv4/IPv6 (หน่วย 1)
ISPInternet Service Provider — ผู้ให้บริการอินเทอร์เน็ต (หน่วย 1)
JavaScriptภาษาโปรแกรมที่ทำให้หน้าเว็บโต้ตอบได้ ทำงานในเบราว์เซอร์ (หน่วย 1, 4)
LANLocal Area Network — เครือข่ายในพื้นที่จำกัด เช่น ห้องเรียน อาคาร (หน่วย 1)
Latency (เลเทนซี)เวลาที่ข้อมูลใช้เดินทางไป-กลับ ดูได้จาก ping (หน่วย 1)
LCPLargest Contentful Paint — เวลาที่เนื้อหาหลักแสดง ควร ≤ 2.5 วินาที (หน่วย 5)
Let's Encryptหน่วยงานออกใบรับรอง HTTPS ฟรีแบบอัตโนมัติ (หน่วย 5)
localhost (127.0.0.1)ชื่อที่หมายถึงเครื่องของเราเอง ใช้ทดสอบเว็บก่อนเผยแพร่ (หน่วย 3)
Media queryเงื่อนไข CSS ตามลักษณะจอ เช่น @media (min-width: 768px) (หน่วย 4)
Meta tagแท็กใน <head> ให้ข้อมูลเกี่ยวกับหน้า เช่น charset, viewport, description (หน่วย 3)
MIME typeชนิดของไฟล์ที่ส่งใน Content-Type เช่น text/html, image/webp (หน่วย 1)
Mobile-firstแนวทางออกแบบ/เขียน CSS สำหรับมือถือก่อนแล้วค่อยขยาย (หน่วย 2, 4)
Mockupภาพออกแบบหน้าเว็บที่เหมือนจริง มีสี ฟอนต์ ภาพ (หน่วย 2)
MoSCoWวิธีจัดลำดับความต้องการ: Must, Should, Could, Won't (หน่วย 2)
MySQL / MariaDBระบบจัดการฐานข้อมูลเชิงสัมพันธ์ ใช้กับ WordPress (หน่วย 3, 5)
Name Server (NS)เซิร์ฟเวอร์ที่เก็บ DNS record ของโดเมน (หน่วย 1, 5)
NATการแปลง Private IP หลายเครื่องให้ออกอินเทอร์เน็ตด้วย Public IP เดียว (หน่วย 1)
Nginxโปรแกรมเว็บเซิร์ฟเวอร์ประสิทธิภาพสูง อ่านว่า “เอ็นจิน-เอ็กซ์” (หน่วย 3, 5)
Open Graphmeta tag กำหนดชื่อ คำอธิบาย และภาพเมื่อแชร์ลิงก์ในโซเชียล (หน่วย 3)
Packet (แพ็กเก็ต)ข้อมูลชิ้นเล็กที่ถูกแบ่งเพื่อส่งผ่านเครือข่าย (หน่วย 1)
Path (พาธ)ตำแหน่งไฟล์/โฟลเดอร์ · Relative, Root-relative, Absolute (หน่วย 1, 3)
PDPAพ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล — ต้องแจ้งวัตถุประสงค์และเก็บข้อมูลเท่าที่จำเป็น (หน่วย 5)
Permalinkรูปแบบ URL ถาวรของหน้า/โพสต์ใน WordPress เช่น /about-us/ (หน่วย 5)
Personaตัวแทนผู้ใช้สมมติที่สร้างจากข้อมูลจริง (หน่วย 2)
PHPภาษาฝั่งเซิร์ฟเวอร์ สร้างหน้าเว็บแบบไดนามิก WordPress เขียนด้วย PHP (หน่วย 3, 5)
Plugin (ปลั๊กอิน)ส่วนเสริมเพิ่มความสามารถให้ WordPress (หน่วย 5)
Port (พอร์ต)“ประตู” ของบริการบนเครื่อง เช่น 80 HTTP, 443 HTTPS, 22 SSH (หน่วย 1)
Propagationช่วงเวลาที่การเปลี่ยน DNS กระจายไปทั่วโลก ขึ้นกับ TTL (หน่วย 5)
PrototypeMockup ที่เชื่อมลิงก์ให้กดทดลองใช้ได้ (หน่วย 2)

Redirect (301/302)การส่งผู้ใช้ไปยังที่อยู่ใหม่ · 301 ถาวร · 302 ชั่วคราว (หน่วย 1, 5)

Responsive designการออกแบบให้เว็บปรับตามขนาดจอทุกอุปกรณ์ (หน่วย 2, 4)

Semantic HTMLการใช้แท็กตามความหมาย เช่น header, nav, main, footer (หน่วย 3)

Sitemapแผนผังโครงสร้างหน้าเว็บทั้งหมด (และไฟล์ sitemap.xml สำหรับ Google) (หน่วย 2, 5)

Static / Dynamicเว็บที่ส่งไฟล์สำเร็จรูป / เว็บที่สร้างหน้าใหม่จากโปรแกรมและฐานข้อมูล (หน่วย 1)
